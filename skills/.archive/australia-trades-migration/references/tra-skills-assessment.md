# TRA 职业评估明细 (2026-08 经Wayback存档核实)

来源: Trades Recognition Australia 官网指南 PDF + 页面存档 (Wayback Machine)。

## 程序与费用 (AUD)

| 程序 | 用途 | 费用 |
|---|---|---|
| MSA (Migration Skills Assessment) | 189/190/491 永久技术移民，纯文件评估 | $795 + 复审$610 |
| OSAP (Offshore Skills Assessment) | 特定国别+职业(海外技工)，文件+技术面试 | 文件$1,280 + 面试P1 $2,000 / P2 $900 |
| TSS (Temporary Skills Shortage) | 482/SID 雇主担保签证 | 文件$1,120 + 面试P1 $2,000 / P2 $900 |
| MPA (Migration Points Advice) | 打分建议 | $450 + 复审$375 |
| SAOM (电工试点) | 补贴项目 | 免费 |

TSS 2025-09 版完整费率 (GST Excl):
- Documentary Evidence $1,120 / Review $700 / Reassessment $450
- Technical Interview P1 $2,000 / P1 Review $700 / P1 Reassess $1,000
- Technical Interview P2 $900 / P2 Review $700 / P2 Reassess $450
- Practical Assessment $2,200 (仅电工强制) / Review $700 / Reassess $1,100

注: OSAP 2019版文件费$1,280 vs TSS 2025版$1,120 — 以官网最新为准，两程序结构相同。

## 经验要求 (Pathway 1: 无澳洲VET学历)
- Licensed trade 有正式培训=4年 / 无培训=6年
- Non-licensed trade 有正式培训=3年 / 无培训=5年
- 均须含: 申请前3年内12个月全职相关经验
- 兼职按比例折算 (如20h/周×2年=12个月全职)
- **Carpenter = non-licensed** (licensed仅Electrician General/Special Class)

## 材料清单 (详细)
1. 护照身份页 — 彩色扫描，≥150dpi，PDF，单文件≤10MB
2. 学历: 最终证书/学徒证 + 完整成绩单(含起止日期+课程明细)
3. Employer Template — 每段雇佣各一张: 起止日期/正常工时/雇佣性质(FT/PT/casual)/岗位/详细任务描述/公司抬头纸/授权人姓名职位联系方式签名+监督时长
4. 工资证据 — 每年至少2种: 政府税单/3张工资单/社保记录/银行流水(显示雇主名+工资入账)
5. 自雇 — 营业执照/行业许可/年报/客户与供应商发票/银行流水/会计师证明/税务文件
6. 非英文材料 — 澳洲境内NAATI认证翻译；境外官方认证翻译(机构抬头+公章+译者签名电话)
7. 雇主模板职责描述不能照抄ANZSCO — 会被拒

## 流程
在线注册(TRA Online Portal) → 选RTO → 交文件评估费 → 文件评估 → (通过则)技术面试 → 结果信
- 技术面试: 全英文、无翻译；在线需笔记本/台式+10Mbps下载/5Mbps上传；手机平板不行
- 时限: TSS/OSAP约9周；MSA 120天
- 失败: 28天内申诉($700，原证据成功可退)；12个月内重评一次/阶段
- 成功: non-licensed发Certificate III(如CPC30220 Carpentry)；licensed发OTSR可申请临时执照
