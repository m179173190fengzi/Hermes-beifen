# V4 双均线交易系统

> 基于B哥双均线方法论 + 链上回测验证
> 级别: **只跑4H**（日线/周线条件过严不触发）
> 标的: BTC-USDT-SWAP
> 方向: **双向** — 由市场方向过滤决定（详见 §市场方向过滤）

## 一、6条均线（固定不改）

| 均线 | 周期 |
|:----|:----:|
| SMA20, SMA60, SMA120 | 简单移动平均 |
| EMA20, EMA60, EMA120 | 指数移动平均 |

## 二、核心概念

| 状态 | 定义 | 含义 |
|:----|:----|:------|
| **均线密集** | 6线价差<3% | 持仓成本趋同，即将选方向 |
| **均线发散** | 6线打开排列 | 趋势运行中 |
| **循环** | 密集→发散→密集→发散... | 永续循环 |

## 三、市场方向过滤（关键！）

### 核心逻辑：价格 vs 日线MA120

```
日线MA120上方（涨过120日均线）= 🐂 牛市区域 → 只做多
日线MA120下方（跌穿120日均线）= 🐻 熊市区域 → 只做空
```

**为什么不用MA120斜率？**  
2026-07-18已验证：斜率版本回测亏损-27.21%。

- MA120斜率太滞后。2023年BTC从$16k涨到$44k，但MA120还在惯性向下，斜率信号到23年下半年才转多
- 价格位置信号在2023年1月就转多了（BTC突破$17k站上MA120），早了半年

### 回测验证（价格位置过滤）— 待跑

需要修改 `~/v4-long-backtest.py` 把日线MA120斜率过滤改为价格位置过滤：

```python
# ❌ 当前代码（斜率过滤，已弃用）
df_d['MA120_60d_ago'] = df_d['MA120'].shift(60)
df_d['ma120_trend_up'] = df_d['MA120'] > df_d['MA120_60d_ago']

# ✅ 改为价格位置过滤
df_d['price_above_ma120'] = df_d['c'] > df_d['MA120']
```

然后在开仓条件处把 `if not trend_up: continue` 改为 `if not price_above_ma120: continue`。

**位置版本预期优势：**
- 2023年1月BTC突破$17k站上MA120 → 比斜率信号**早半年**转多
- 价格位置信号更灵敏，应能同时保留2023和2024的做多机会

### 实现方式

```python
# 日线MA120
df_d['MA120'] = df_d['c'].rolling(120).mean()
# 价格在MA120上方 = 牛市区域
df_d['bull_zone'] = df_d['c'] > df_d['MA120']
```

在4H级别做交易决策时，查最新日线收盘的 `bull_zone`：
- `bull_zone=True` → 只做多
- `bull_zone=False` → 只做空

详见 `scripts/v4-backtest-methodology.py`。

### ① 均线密集突破开仓法（主入场）
```
条件:
1. 6条均线价差<3%（密集状态）
2. 价格跌破所有均线下方
3. 连续2-3根4H收盘确认
→ 开空

止损: 回到密集区上方1%（"你怎么开的怎么止"）
止盈: 前一个4H密集区 / 固定1:3
```

### ② 回踩MA20不破开仓法（加仓/二次入场）
```
条件:
1. 之前出现过均线密集+向下突破
2. 价格第一次回踩SMA20或EMA20
3. 收盘在MA20下方0.5%以内（没站上去）
→ 开空/加仓

⚠ 历史回测警告: 此方法占89%交易但多数被止损
   需要额外趋势过滤（如MA20本身向下）
```

## 四、出场方法（三个）

| 方法 | 适用场景 | 做法 |
|:----|:---------|:-----|
| ① 赔率平仓法 | 通用 | 固定1:3或1:5，到了就走 |
| ② 前密集区平仓法 | 趋势中 | 前一个4H密集区=目标位 |
| ③ 止损法 | 通用 | 怎么开怎么止（见入场方法） |

## 五、仓位公式

```
单笔风险 = 本金 × 1.5%（普通） / 2.0%（高分机会）
仓位 = 风险金额 / (入场价 × 止损百分比)
杠杆 = 仓位价值 / 本金

注: 表面杠杆不重要，实际杠杆=开仓价值/本金才重要
```

## 六、六维评分（0-10分）

| 维度 | 满分 | 评分逻辑 |
|:----|:---:|:---------|
| ① 结构阶段 | 2.5 | 密集=高分 发散=低分 |
| ② 突破确认 | 2.0 | 已突破/回踩=高分 |
| ③ 成交量 | 1.5 | 突破放量=高分 |

| ⑤ BTC环境 | 1.0 | 大盘配合=高分 |
| ⑥ 方向信号 | 1.0 | 有突破或回踩信号=高分 |

```
≥8.0 🔥突破机会  ≥6.5 🟢可交易  ≥5.0 🟡观察  <5.0 🔴等待
```

## 七、账户风控

```
单笔风险: ≤1.5%本金
日亏≥3%: 停手
连亏2笔: 仓位减半
连亏3笔: 停手复盘
周回撤≥6%: 停主动交易
回撤≥10%: 恢复模式（仅减仓）
```

### 已知问题
- **EMA20 < SMA20** 在周线永远不触发（EMA权重偏向近期价格）
- **Smooth decline波动率阈值** 在日线过严（闪崩日线震幅6-10%）
- **回踩MA20入场太松** — 横盘震荡时反复被止损
- **突破入场止损太紧** — 回到密集区就止会被震出去
- 2025年4月BTC闪崩V型反转，V4系统正确规避（smooth decline过滤）

## 九、关键原则

1. **你怎么开仓的，就怎么止损** — 如果按密集区突破开，回到密集区就止
2. **胜率30-40%正常** — 高赔率（1:3+）系统必然是低胜率
3. **不要梭哈** — 只用交易资金的30%做合约
4. **开仓必带止盈止损** — 开仓前就算好赔率
5. **看大做小** — 大周期看方向，4H找入场
6. **新手只做BTC/ETH/SOL** — 流动性好，不易被操纵
7. **手续费是成本** — 用返佣链接注册，降低交易成本
