# Meme 币钱包监控 / 跟单方法论

用别人的钱包来提高打狗胜率。本技能覆盖「**跟谁、什么时候跟、怎么过滤、怎么退出、为什么会被割**」全链路，全部阈值带来源。
完整来源版见 `references/wallet-copy-trading-playbook.md`。

## 触发条件

- 用户问「怎么挑值得跟的钱包 / 怎么跟单 / 钱包监控打狗」
- 用户给出「监控某些钱包 → 跟着买」的方案，想优化参数
- 用户问跟单为什么亏、共识信号怎么设、退出怎么做

## ⚠️ 先纠正三个高频错误（踩过的最贵的坑）

1. **GMGN 的 `fomo` 标签是「平台使用标签」，不是「聪明钱标签」。** 官方博客证实：某币前 100 持有者里 42 个带 fomo 标签、前 100 交易者里 45 个——一个上万人的大集合，过滤度极低。且 fomo.family 的 top traders 偏长期囤币型，不是 meme 波段手。**别把 fomo 标签当筛选依据。**
2. **「30 天已实现盈利 TOP5」是最易被证伪的选钱包方式。** 用被当证据的已实现结果来排序 = 循环论证，天然奖励自导自演/刷量/运气样本。原文："A win rate is an output, not evidence."
3. **「≥2 钱包 / 48h 共识」过松。** meme 场景应 **≥3 个独立钱包 / 30–60 分钟窗口**；48h 会把弱关联也计成共识（Reign 对 meme 建议 min 2、窗口 30m）。

## 1. 选钱包阈值

| 指标 | 阈值 | 备注 |
|---|---|---|
| 7 天胜率 | 50%–90%（无好钱包可放宽 40%） | shitcoin 里 >50% 已不错 |
| 更严实盘样本 | 70%+ 胜率 / 50+ 笔 | 扫 1 万钱包只余约 100 个「真钱包」 |
| 交易样本量 | 7 天 ≥100 笔 TX | 区分活跃真钱包 vs 几笔高胜率小号 |
| 平均持仓 | 避开秒级；GMGN 把「5 秒内买卖」标 Phishing | 秒级 = 机器人/农民，跟不了 |
| 单笔 vs 池子 | 单笔相对池子要小 | 吃薄池子大比例 = 需要你接盘 |
| 记录稳定性 | 7D vs 30D 并排 + 去掉单笔最好交易后仍成立 | 只在最近几天赚钱 = 热手 |
| 资金源 | 拒绝与部署者共用 CEX 子账户/桥的钱包 | 研究者称 99% 的「Smart Money」是内部人 |

**5 问筛选法**（全可用公开数据）: ①钱从哪来 ②谁资助它/它资助谁 ③多老多稳 ④优势是否依赖「抢第一」（若依赖则结构不可复制）⑤是否卖信号/收费群（真 alpha 不公开）。

## 2. 择时：延迟吃多少

- 延迟拆解：上链 400ms + 索引 1–5s + 扫描 0.5–3s + 警报 0.5–2s + 人反应 0.2–0.5s + 下单 400ms → **乐观 3–7s，现实 10–30s**。
- 新盘头 30 秒常从 $50k 涨到 $150k–$250k → 跟单以 **3–5x 原价**入场。
- 回测证据：**头 10 秒入场赚钱；1–10 分钟窗口（人看到推送再点）亏得最多**——那就是接盘流动性。
- 结论：**只跟「edge 能扛过你延迟」的钱包**；**流动性 <$50k 的薄池子新盘不跟**；把检测→下单做成机器对机器（去掉人反应 1–2s）。

## 3. 共识 / 集群窗口

- 独立集群检测默认 `min_wallets=3, window=15min`（按钱包评分加权）；Reign meme 建议 min 2、窗口 30m；Nansen 口径 10+/48h（面向更大市值）。
- **推荐：≥3 个「资金源互不相同」的独立钱包在 30–60 分钟内同买。** 2 钱包/48h 只做「观察」。
- **共识可被伪造**：同一时间创建的钱包、相同资金源、同批代币同步买卖、卖出后利润回流同一地址 → 一个实体伪装成多地址。关联集群控制某币 **>20% 供应** = 不碰。

## 4. 过滤器阈值（GMGN 默认线 + 有数据支撑的优先级）

- GMGN 默认筛线：**Top10 = 30%、DEV = 30%、Insiders = 5%、Phishing = 5%、Bundlers/Fresh/Sniper/Rugged = 10%**（可改，非安全承诺）。
- Bundle% 是「**多少成交量来自打包**」，≠ 安全评级，跨平台口径不可比（Axiom 口径：同一区块 ≥4 笔）。
- **反直觉**：首槽 bundle / 早期重仓钱包在**跑出来的币上出现得更多**（snipers 跟着注意力走）→ bundle 是「你在跟谁付钱」的警告，不是失败证据。
- **命中率提升最明显的过滤器（按数据）**：创建者**非连环发币（窗口内 <3 次）** + 元数据**有官网** + **有 Twitter 主页** → 100k 峰值率从 2.2% 抬到 15.2%。连环发币者几乎不跑（0/276）；无官网 0/308。
- 蜜罐：BSC/ETH 必先**模拟买+卖**（honeypot.is / GoPlus / Guava）；用带卖前模拟器的执行端。

## 5. 退出纪律

- 仓位：单笔 **1–2%** 资金；止损按入场大小反推（蓝筹 -20%、新低市值 -80%，或统一 -30%~-40%）；每日亏损上限硬编码、触发即停。
- 止盈阶梯：**2x 卖 50% 收回本金 → 5–10x 再卖 25% → 剩余挂 25–35% 移动止损**（或 2x/4x 各卖 25% + 移动止损）。
- 移动止损宽度：15–20% 快进快出 / 25–35% 甜点区 / 40–50% 高信念。
- **时间止损**：预设 12h/24h/3d，窗口内不涨即撤（动量型尤其适用）。
- **出场独立于被跟钱包**：用自设 TP/SL（关闭 follow-selling），因为你的卖单必然晚于它、砸在它压低的簿里。

## 6. 失败模式速查

钱包本身是 dev/内部人（资金树 15–50 地址）· 伪造战绩（自己发币+隐藏钱包拉盘）· 你成了它的退出流动性 · 蜜罐（能买不能卖）· Gas 战/三明治（BSC 高发，案例 four.meme Mubaraking 抢跑获利 11.2 BNB）· 迟到+滑点+失败交易（失败仍扣费）· 钱包碎片化（KOL 用 3–7 个钱包，跟的是它想让你跟的那个）· 选择性晒单/幸存者偏差 · 波动中卖不出去 · 钓跟单者的「农民」钱包 · 费用复利（fomo.family 每笔最低 $1，< $300 起步难盈利）· 链 reorg。

## 7. 工具选型（钱包监控/跟单维度）

- **GMGN**：免费、最快、SOL 原生；Smart Money feed / Rank / Radar / Track（可按 Win Rate、Avg Duration 排序）；Copy Trade **仅 SOL**、最多 10 任务，可设市值/流动性/最低燃烧 LP/最低最高跟单额/黑名单；**无复杂条件警报**。
- **Cielo**：纯监控层，多链 + Telegram/Discord 推送（免费 50 SOL 钱包 / Pro $59 / Whale $199），无发现引擎无交易。
- **Nansen**：实体标签 + 40+ 链 + 复合聪明钱 + 警报，但仪表盘慢几分钟，不适合 meme 狙击。
- **Reign**：专做集群警报（本报告里共识信号最直接的实现）。
- **执行端**：Banana Gun（跨链 Copy Trade 2.0 + 卖前模拟器拦蜜罐）> Trojan（快但卖端无模拟器）/ BullX（模拟器缺口）/ Axiom（跟踪+手动执行，官方未证实自动跟单）/ Photon / Maestro（记录显示不支持钱包跟踪）。
- 开源自建：`cnm750x/four.meme-copy-trading`（BSC，four.meme + PancakeSwap）。详见 references。

## 8. 十条可落地规则

1. 别把 fomo 标签当聪明钱；只留「资金源互不相同 + 7D≥100 笔 + 30 天并排稳定」。
2. 入场门槛：7 天胜率 50–90%、7 天 ≥100 笔、平均持仓 >1 分钟。
3. 共识收紧：≥3 独立钱包 / 30–60 分钟内同买。
4. 只在流动性 ≥$50k 的币上跟；薄池子新盘不跟。
5. 过滤优先级：非连环发币 + 有官网 + 有 Twitter 主页。
6. 结构：Top10 ≤30%、DEV ≤30%、Insiders ≤5%、Sniper/Bundler ≤10%，前 100 累计占比 + 资金来源，关联 >20% 不碰。
7. 蜜罐必检：模拟买+卖；用带卖前模拟器的执行端。
8. 仓位 1–2%；止损 -20%(蓝筹)/-30~40%(低市值)；每日亏损上限硬编码。
9. 止盈 2x 卖 50% → 5–10x 卖 25% → 剩余 25–35% 移动止损；12–24h 时间止损。
10. 出场用自设 TP/SL，独立于被跟钱包。
