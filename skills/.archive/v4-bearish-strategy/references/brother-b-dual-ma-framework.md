## 核心原理

行情永远在两种状态中循环：
```
均线密集(蓄力) → 均线发散(趋势) → 均线密集(蓄力) → 均线发散(趋势)
```

### 均线密集
6条均线缠绕在一起，分不清谁上谁下 → 蓄力阶段，即将选择方向。

### 均线发散
均线打开，短期均线在极端位置、长期在另一端 → 趋势正在进行。

## 两个制式入场方法

### 方法1: 均线密集开仓法

```
1. 找到当前时间级别的均线密集区
2. 观察k线与均线密集的关系:
   - 价格跌破均线密集 + 反弹不上来 → 做空
   - 价格站上均线密集 + 回踩不破 → 做多
3. 止损: 价格回到均线密集区
4. 盈亏比: 通常1:3+
```

### 方法2: 第一次回踩20均线不破开仓法

```
1. 均线密集突破后,趋势已经确立
2. 等待价格第一次回踩MA20/EMA20
3. 回踩不破20均线 → 加仓/入场
4. 止损: 价格有效跌破20均线 (止损极小)
```

## 三个出场方法

| 方法 | 用法 |
|:----|:------|
| 赔率平仓法 | 开仓前定好1:3/1:5,到了就走,不过夜 |
| 前一个均线密集平仓法 | 趋势中的支撑/压力 = 前一个密集区,到了就止盈 |
| 斐波那契平仓法 | 突破历史新高时,用Fib Extension (1.618/2.618/3.618)分批止盈 |

## 止损铁律

> **你怎么开仓的,就怎么止损**

- 均线密集开仓 → 价格重回密集区止损
- 回踩20线上车 → 跌穿20线止损

## 胜率认知

## 仓位

- 单笔固定亏损金额 (e.g. 每笔最多亏$10)
- 仓位 = 可亏金额 / (入场价 - 止损价)
- 表面杠杆无意义,要看实际杠杆: 开仓价值/本金
