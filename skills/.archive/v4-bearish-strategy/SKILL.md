# V4 熊市做空策略 (AlphaTrader Elite Edition)

> **只跑4H级别**。日线/周线的EMA20\<SMA20和smooth decline条件过严无法触发。

## 六条均线（固定参数，不改）

| 均线 | 周期 |
|:----|:----:|
| SMA20 | 20根4H |
| SMA60 | 60根4H |
| SMA120 | 120根4H |
| EMA20 | 20根4H |
| EMA60 | 60根4H |
| EMA120 | 120根4H |

## 入场条件（同时满足）

### A. 空头排列（6均线检查）
```
SMA20 < SMA60 < SMA120
EMA20 < EMA60 < EMA120
EMA20 < SMA20   ← 短期动量向下
```

### B. 平滑下跌（最近10根4H）
```
① 跌幅≥2%:      (highs[0] - lows[-1]) / highs[0] >= 2%
② 波动率≤1.2%:  平均K线震幅 / 收盘价 ≤ 1.2% (4H级别专用)
③ 更低高点:     后5根平均高点 < 前5根平均高点
```

## 出场条件（任一项触发即平）

```
止损:     入场价 × 1.05 (5%)
止盈:     入场价 × 0.90 (1:2盈亏比)
排列失效: SMA20不再小于SMA60
```

## 六维评分系统 (0-10分)

| 维度 | 满分 | 说明 |
|:----|:----:|:-----|
| 方向+趋势强度 | 2.5 | 均线发散度越大越高 |
| 关键位置优势 | 2.0 | 价格在SMA20下方距离 |
| 成交量确认 | 1.5 | 下跌是否放量 |
| 下跌质量 | 1.5 | 平滑程度+跌幅 |
| 盈亏比 | 2.0 | 潜在利润/风险 |
| BTC环境 | 1.0 | 排列+平滑同时成立 |

```
≥8.5: 🔥 强趋势   → 积极入场, 风险可放宽到2%
7-8.5: 🟢 可入场   → 轻仓试单
5.5-7: 🟡 机会一般 → 等更好位置
<5.5:  🔴 不做     → 等待
```

## 仓位管理

```
单笔风险: 1.5%本金 (评分≥8.5可放宽到2%)
仓位 = (本金 × 风险比例) / (入场价 × 止损百分比)
连亏2笔 → 风险减半 (0.75%)
连亏3笔 → 停手复盘
```

## 账户风控

| 规则 | 阈值 | 动作 |
|:----|:----:|:-----|
| 单日亏损 | ≥3% | 停手 |
| 连续亏损 | ≥2笔 | 仓位减半 |
| 连续亏损 | ≥3笔 | 停复盘 |
| 周回撤 | ≥6% | 停主动交易 |
| 账户回撤 | ≥10% | 仅减仓 |
