# V4 交易系统

V4是一套专职于**熊市做空**的系统化交易策略，基于6均线空头排列确认+趋势强度评分+账户风控的完整决策流程。

## 核心原则

- **6均线固定**：SMA20/60/120 + EMA20/60/120，永不修改周期
- **看大做小**：大周期确认方向 → 逐级向下搜索小周期找入场
- **熊市只做空**：只在空头排列确认时交易
- **参考走势**：默认BTC，分析前先看BTC脸色
- **趋势优先**：评分<5.5不做，强趋势才积极
- **回测只用4H**：EMA20<SMA20和smooth decline在日线/周线不触发（已验证），4H是V4最优工作频率

## 工作频率

| 频率 | V4适用性 | 原因 |
|:----|:--------:|:-----|
| **4H** | ✅ **推荐** | 58.3%胜率 / 9.79%收益（历史回测最优）|
| 1H | ✅ 可用 | 信号较多，胜率低于4H |
| 15m/1m | ❌ 不适合 | 信号质量差，长期亏损(-17.49%) |
| 日线 | ❌ 不触发 | EMA20<SMA20几乎不触发；暴跌时日线震幅>1.5%过不了smooth decline |
| 周线 | ❌ 不触发 | EMA20永远>SMA20；周线平均震幅8-10%；等排列好时底部已过 |

## 平滑下跌条件（4H校准版）

```
最近10根4H蜡烛:
① 跌幅 ≥ 2%           (highs[0] - lows[-1]) / highs[0] >= 0.02
② 波动率 ≤ 1.2%        平均K线振幅 / 当前价格 <= 0.012
③ 后5根更低高点        后半段平均高点 < 前半段平均高点
```

**阈值按时间框架调整（只改这一个参数）：**
- 4H: 1.2% ✅ 基准
- 1H: 1.5%
- 15m: 2.0%
- 日线: 1.5%

## 交易流程

```
V4脚本跑 → 多周期MA检查 → 六维评分 → 风控检查 → 结论输出
                                              ├ 评分≥7.0 + 风控通过 → 执行下单
                                              └ 评分<5.5 → 不做，等待
```

## 六维评分系统（0-10分）

| 维度 | 分值 | 说明 |
|------|------|------|
| ① 大周期方向+趋势强度 | 0-2.5 | 均线排列方向+发散度 |
| ② 关键位置优势 | 0-2 | 价格相对MA/支撑/压力的位置 |
| ③ 成交量确认 | 0-1.5 | 放量下跌 vs 缩量反弹 |
| ④ 下跌平滑度 | 0-1.5 | 平滑下跌 vs 剧烈波动 |
| ⑤ 盈亏比 | 0-2 | 潜在R:R，强趋势可接受≥1.8 |
| ⑥ BTC环境 | 0-1 | 大盘配合度 |

### 评分解读
- **≥8.5**: 🔥 强趋势空单机会，积极参与
- **7.0-8.5**: 🟢 可入场，严格按计划
- **5.5-7.0**: 🟡 等更好位置
- **<5.5**: 🔴 不做，等待

## 账户风控

```
单笔风险:       1.5%本金（强趋势≤2%）
单日最大亏损:   3%
连亏2笔:       仓位减半
连亏3笔:       停止交易，复盘
周回撤超6%:    停主动交易
账户回撤10%+:  恢复模式，仅减仓
```

### 仓位公式
```
单笔可亏金额 = 账户本金 × 单笔风险比例
止损幅度 = 入场价到止损价的百分比
合理名义仓位 = 单笔可亏金额 ÷ 止损幅度
```

### 加仓纪律
- 只能盈利+结构确认后加仓
- 🚫 亏损绝不补仓
- 🚫 不为摊成本补仓
