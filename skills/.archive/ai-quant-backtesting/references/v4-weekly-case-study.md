# V4 周线回测案例研究

> 证明：V4策略的EMA20<SMA20和smooth decline条件在周线级别无法触发

## 回测设定

- **标的**：BTC-USD
- **周期**：2022-2024（周线）
- **数据源**：yfinance（从2019年开始获取，确保SMA120有足够数据）
- **账户**：$100,000

## 版本对比

### V1：完整V4条件

条件：SMA20 < SMA60 < SMA120 AND EMA20 < EMA60 < EMA120 AND EMA20 < SMA20 AND smooth decline（10周更低高点和更低低点 + 平均震幅<6%）

**结果：0笔交易触发**

失败原因分解：
| 条件 | 在周线表现 |
|------|-----------|
| SMA20 < SMA60 < SMA120 | ✅ 2022年11月-2023年5月触发 |
| EMA20 < EMA60 < EMA120 | ✅ 同期触发 |
| EMA20 < SMA20 | ❌ **从不触发** — 周线EMA永远比SMA高（近期权重原因） |
| smooth decline avg_range<6% | ❌ BTC周线平均震幅8-10% |
| smooth decline 10周趋势下降 | ❌ 2022年11月时BTC已从16K反弹 |

### V2：简化版（仅SMA排列）

条件：SMA20 < SMA60 < SMA120（去掉EMA20<SMA20和smooth decline）
出场：止损10% / SMA排列打破

**结果：3笔交易，胜率0%，总收益-3%**

| 日期 | 入场 | 出场 | 盈亏 | 原因 |
|------|:----:|:----:|:---:|:----:|
| 2023-01 | $16,975 | $18,672 | -10% | stop |
| 2023-03 | $22,934 | $25,228 | -10% | stop |
| 2023-05 | $27,140 | $27,193 | -0.2% | alignment broken |

## 根因分析

1. **周线SMA排列滞后**：SMA20<SMA60<SMA120形成时（2022年11月底），BTC已经从$16,000底部反弹，价格趋势已经向上
2. **周线波动率过高**：平均震幅8-10%，V4的smooth decline阈值6%无法通过
3. **周线EMA特性**：EMA权重偏向近期，在恢复行情中EMA20永远高于SMA20
4. **"看大做小"是正确的**：大周期确认方向，小周期找入场。Trying to use V4 directly on weekly is a frequency mismatch.

## 教训

| 不做什么 | 要做什么 |
|---------|---------|
| ❌ 在周线直接用V4条件触发交易 | ✅ 周线只看方向（趋势强度评分） |
| ❌ 等周线SMA排列好再做空 | ✅ 4H/1H级别用V4找入场 |
| ❌ 周线级别用smooth decline | ✅ 小周期用smooth decline（震幅小） |
