# V4 Trend Trading — 熊市做空策略系统

> 完整交易决策系统：先评分 → 再风控 → 再下单

## 核心逻辑

V4是**熊市专属**的做空策略，不做多。核心判断链：

```
大周期MA排列 → 小周期找入场 → 趋势强度评分(0-10) → 风控检查 → 仓位计算 → OKX执行
```

### 六均线

**固定参数，永不修改：**
- SMA20, SMA60, SMA120
- EMA20, EMA60, EMA120

### 熊市排列条件（全部满足才算）

```
SMA20 < SMA60 < SMA120   （空头排列）
EMA20 < EMA60 < EMA120   （EMA确认）
EMA20 < SMA20            （短线动量向下）
```

### 平滑下跌条件（辅助确认）

```
最近10根K线连续降低高点和低点
总跌幅 ≥ 2%
平均K线范围 ≤ 1.5%（排除剧烈波动）
```

## 六维趋势强度评分 (0-10)

专为V4熊市做空设计，脚本 `~/v4-strategy.py` 自动计算：

| 维度 | 分值 | 核心逻辑 |
|------|------|---------|
| ① 大周期方向+趋势强度 | 0-2.5 | MA排列方向 + 均线发散度 |
| ② 关键位置优势 | 0-2 | 价格相对SMA20/SMA60位置 |
| ③ 成交量确认 | 0-1.5 | 放量下跌 vs 缩量 |
| ④ 下跌平滑度 | 0-1.5 | 下跌是否均匀无毛刺 |
| ⑤ 盈亏比 | 0-2 | 距支撑 vs 距阻力的比例 |
| ⑥ BTC整体环境 | 0-1 | 大盘是否配合 |

### 评分解释

| 评分 | 动作 | 仓位 |
|------|------|------|
| ≥8.5 🔥 | 强趋势空单机会，积极参与 | 可放宽至2%风险 |
| 7.0-8.5 🟢 | 短空机会，可入场 | 1.5%风险 |
| 5.5-7.0 🟡 | 机会一般，等更好入场 | 轻仓或不做 |
| <5.5 🔴 | 不做，等待 | 0 |

## 账户风控

```
单笔风险:         普通1.5% / 强趋势2%
日亏损上限:       3% → 停手
连亏2笔:          仓位减半
连亏3笔:          停交易复盘
周回撤6%:         停主动交易
回撤10%+:         恢复模式(仅减仓)
```

### 仓位计算

```
可亏金额 = 本金 × 风险比例
止损幅度 = (入场价 - 止损价) / 入场价
仓位 = 可亏金额 / 止损幅度
杠杆 = 仓位 / 本金
```

### 加仓纪律

- **只能**在盈利 + 结构确认下加仓
- 🚫 亏损绝不补仓
- 🚫 绝不为摊低成本补仓

## 自动执行工作流

当评分≥7.0且风控通过，V4脚本的结论直接驱动OKX下单：

1. V4脚本输出评分和风控检查
2. 参考结论中的建议仓位和止损
3. 执行 `okx swap place --instId BTC-USDT-SWAP --side sell --ordType market --tdMode cross --posSide short`
4. 同时附加止损止盈
5. 运行 `okx swap positions` 确认成交

```bash

```

输出包含：

- 每周期评分明细
- 结构化结论（评分→结构→风控→建议）

## 数据源

- 价格数据：OKX CLI `okx market candles`（BTC-USDT-SWAP）
- 风控状态：`~/.v4_trade_state.json`（自动创建和管理）

## 注意事项

- ⚠️ V4是**熊市做空策略**，牛市不做
- ⚠️ 评分<5.5时强行开单违反系统纪律
- ⚠️ 参考走势默认BTC，山寨币做空需额外判断
- ⚠️ `~/.v4_trade_state.json` 中的 `account_balance` 需要手动更新为真实本金
