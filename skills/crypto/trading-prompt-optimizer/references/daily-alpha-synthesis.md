# 每日Alpha合成 —— 多cron合并工作流

## 背景

原来两个独立的19:00 cron job（链上打狗 + 推特监控）合并为一个「每日Alpha合成简报」。

## 合并逻辑

```
旧方案:
  链上打狗 (19:00) → 只扫链+过滤+评分
  推特监控 (19:00) → 只搜推文+TVL
  → 用户收到两条消息，信息割裂

新方案:
  每日Alpha合成简报 (19:00) → 链扫+6类过滤+评分+分析师追踪+TVL+交叉验证
  → 用户收到一条完整消息，信息整合
```

## 设计要点

1. **角色定位** — 定义为"每日Alpha情报合成师"，有明确的Profile和市场语境
2. **阶段式分析** — 4个阶段（链扫→分析师追踪→跨链交叉→TVL资金流），每个阶段有独立的分析框架
3. **交叉验证** — 链上信号 vs 推特情绪对照（"链上卖+推特喊涨=🚩，推特冷+链上流入=🐋"）
4. **输出格式** — 分板块的结构化输出（TVL→链上标的→分析师观点→交叉验证）
5. **静默模式** — 三链都无信号时 [SILENT]，不浪费token
6. **自包含** — 不加载任何skill上下文，prompt内容即为完整指令
