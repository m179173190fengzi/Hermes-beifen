# 蒸馏Crypto KOL的实践记录（2026-07-13）

使用女娲蒸馏两位中文币圈KOL（@0xSunNFT + 冷静冷静在冷静）的实操经验。

## 用的什么方法

**没有用女娲完整6-agent pipeline**（会超时+信息不足）。
改为手动流程：
1. `twitter search` 搜KOL名字 → 获取推文和社区提及
2. 手工提炼3-5个**心智模型**（女娲三重验证：跨域+生成力+排他性）
3. 写SKILL.md（心智模型+决策启发式+表达DNA+反模式+诚实边界）

## 为什么不能直接调女娲

| 问题 | 原因 | 解决 |
|:----|:-----|:-----|
| 推文不是书籍 | 没书/没论文/没长访谈 | 手动搜推文更直接 |
| 6-agent超时 | 10min+跑不完 | 降级为3维（表达+对话+他者） |
| 信息有限 | 非公众人物，公开信息少 | 诚实边界标注"基于有限信息" |

## SKILL.md结构（用于crypto KOL的模板）

```markdown
# [人名] · [定位]

## 角色扮演规则
1-5条

## 身份卡
一段话

## 心智模型（3-7个）
### [模型名]
- 核心逻辑：
- 证据：
- 应用：
- 局限：

## 决策启发式（5-10条）
1. 如果[条件] → 则[行动]

## 表达DNA
- 句式/词汇/节奏/确定性/语言

## 价值观与反模式
- 价值观：3-5条
- 反模式：❌不做

## 使用示例
用户问 → 回答

## 诚实边界（L5）★ 必备
1. 信息截止日期
2. 公开表达≠全部想法
3. 蒸馏不了直觉
4. 不能预测新范式

## 调研来源
| Agent | 来源类型 | 数量 | 可信度 |
```

## 触发词设计

```
frontmatter description 控制在300字内：
一句定位 + 明确触发语（「用X视角」「X会怎么看」）
+ 一句「不在一般性问题上自动触发」防呆
```
