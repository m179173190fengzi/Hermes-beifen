# RH (Robinhood Chain) 链上打狗行为模式

> 基于2026-07-18用户分享的实盘观察。RH复制BSC早期路径，核心矛盾是**叙事多而散，资金不够分**。

## 核心模式

RH链的行为特征：**创始人一发推 → 一堆人从各种角度冲 → 各自为战 → 都没拉起来 → 割肉 → 看到别人拉的又追 → 反复横跳反复亏。**

### 输家模式

| 标的 | 为什么输 |
|------|---------|
| **RWA** | Vlad提了一嘴RWA，但RH没有RWA主线，追了就割 |
| **WOLVES** | 暴涨了才去追，自然接盘 |
| **TENDIES** | 被CASHCAT/PONS吸血，资金集中而非扩散 |

## 三条核心规律

1. **好叙事 = 有主线**
   - 创始人随口提一嘴不算叙事
   - 必须是有持续性的赛道（meme / 发射台 / DeFi基建）
   - RWA在RH无主线，提了就凉

2. **大车头 = 有人持续奶**
   - 不是一锤子喊单
   - Vlad持续提meme → CASHCAT持续受益
   - 单次喊单见效短，持续输出才是真车头

3. **拿住不动 = 对抗FOMO**
   - 哪个涨追哪个是亏钱最短路径
   - 好叙事 + 大车头的币，不在乎短期涨跌，耐心等
   - 反复横跳 = 反复被收割

## 资金流动规律

- RH链资金有限，**不会同时拉多个叙事**
- 某个币暴涨时 = 其他币在被吸血
- 资金永远是对的，市场永远是对的
- 不要跟资金对着干，但也不要追已经拉起来的

## 操作原则

1. 发现好叙事 + 大车头的币 → 拿住，不横跳
2. 不追涨 → 追涨是接盘
3. 不FOMO → 暴涨的币晚一步就是接盘侠
4. 耐心等待 → 好叙事会自己起飞
5. 不要哪个涨追哪个 → 这是亏钱最短路径

                           真正涨的是CASHCAT（meme龙头）和PONS（发射台龙头）
