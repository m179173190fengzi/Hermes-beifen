# Robinhood Chain 市场结构观察

> 来源：用户实战经验总结（2026-07-18）
> 与 `robinhood-chain-scoring.md`（技术评分）互补。本文件聚焦市场行为模式。

## 核心规律

RH 链正在复制 BSC 早期的路径。

### 叙事模式

```
创始人发推 → 市场产生多个角度（炒作点）
        ↓
没有清晰主线 → 资金分散 → 各种币各自为战
        ↓
追涨者反复亏钱 → 割肉 → 追下一个 → 再割
```

### 赢家 / 输家

| 类别 | 特征 | 例子 |
|------|------|------|
| ✅ 赢 | 好叙事 + 大车头持续奶 | CASHCAT（meme龙头）、PONS（meme发射台龙头） |
| ❌ 输 | 创始人随口提一嘴的细分赛道 | RWA、WOLVES、TENDIES |
| ❌ 输 | 哪个涨追哪个的反复横跳 | 跟着Vlad发言追RWA→割→追WOLVES→又割 |

## 操作纪律

1. **好叙事 + 大车头 = 拿住不横跳**
   - 不在乎短期涨跌
   - 耐心等待，好的叙事能起飞
   - 参考：CASHCAT（Vlad重视meme方向下的龙头标靶）、PONS（Noxa死后发射台赛道垄断）

2. **资金永远是对的，市场永远是对的**
   - 不要对抗市场共识
   - 如果某个币涨了，说明资金选择了它

3. **不要追涨**
   - 哪个涨追哪个 = 反复被收割
   - 好的标的会给你回踩上车的机会

4. **当没有清晰主线时，管住手**
   - 创始人发推后一堆新的角度出现 ≠ 机会
   - 没有主线时亏大的
   - TENDIES被吸血说明资金在集中而不是扩散

## 信号判断

### 正面信号
- 大车头持续在奶同一个大方向（meme / 发射台 / 某个叙事）
- 龙头币在市场震荡时展现出韧性
- 赛道出现"垄断"格局（如PONS在Noxa死后独占发射台流量）

### 负面信号
- 创始人发推后出现10+个无关角度
- 龙头在跌而杂毛在涨（散乱行情）
- 资金从龙头流入杂毛（吸血 / 出货）
- "追涨 = 第二天被套" 成为常态

## 与BSC的对比

BSC 早期也是同样的剧本：
- CZ 发推 → 一堆蹭概念的币 → 无主线 → 绝大多数归零
- 最终活下来的只有少数有好叙事 + 大车头持续支持的项目
- RH 目前处于同样的早期阶段，CASHCAT/PONS 类似 BSC 上的 CZ系龙头

## 用于评分决策

当分析 RH 链代币时，除了 `robinhood-chain-scoring.md` 的技术评分，必须额外评估：

1. **市场当前是否有主线？** — 有明确主线时龙头优先级最高
2. **该币属于哪个叙事层？** — 龙头、赛道龙头、跟风、蹭热点
3. **大车头是否持续支持？** — 一锤子买卖 vs 持续奶
4. **资金在集中还是分散？** — 龙头涨杂毛跌 = 集中（健康）；杂毛乱舞 = 分散（危险）

**记住：追涨是亏钱最短路径，好叙事+大车头+耐心等待 = 最确定的获利方式。**
