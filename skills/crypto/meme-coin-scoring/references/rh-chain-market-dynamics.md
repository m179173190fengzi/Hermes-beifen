# RH Chain 市场动力学观察（用户经验提炼）

> 来源：2026-07-18 用户分享的真实交易观察。不是猜测，是亏出来的经验。

## 核心规律

**RH链 = BSC早期翻版。** 两条链的动力学几乎一样：

- 创始人一发推 → 各种角度乱冲 → 没有主线 → 大部分人亏钱
- 哪个涨追哪个 = 反复被收割

## 赔钱模式

```
创始人发推 → 多人从不同角度冲不同币
         → 都没拉起来 → 割肉
         → 看到别人拉的暴涨 → 又追 → 回调割肉
         → 反复循环
```

**典型案例**：Vlad发言 → 有人冲RWA（没涨）→ 割肉 → 看到WOLVES暴涨 → 追 → 回调割肉

## 赚钱模式

**好叙事 + 大车头 = 拿住不横跳**

| 币种 | 为什么能涨 | 逻辑 |
|------|-----------|------|
| CASHCAT | Vlad重视meme赛道，CASHCAT是meme龙头 | 赛道龙头 |
| PONS | Noxa没了，PONS是meme发射台赛道垄断 | 赛道垄断 |

## 资金流向规律

1. **资金永远是对的，市场永远是对的**
2. **龙头吸血** — 一个好叙事起来后，其他币被吸血（TENDIES被吸血案例）
3. **赛道容量有限** — RH链资金不够分，同时只能支持1-2个好叙事

## 操作原则

1. **不要哪个涨追哪个** — 这是亏钱最短路径
2. **认准一个好叙事+大车头就躺平** — 不在乎短期涨跌
3. **耐心等待** — 好叙事+大车头永远是对的
4. **没主线时管住手** — 创始人发推各种角度乱舞时，是大亏信号
5. **不在震荡中追涨杀跌** — 等主线明朗

## 与评分系统的关系

当使用 meme-coin-scoring 评估RH链代币时，额外检查：
1. 该币是否属于当前明确的主线叙事（meme/发射台/RWA等）
2. 是否有持续的大V/车头在奶（一锤子买卖不算）
3. 是否处于被龙头吸血的副线位置
4. 如果评分≥70但叙事不清晰 → 降级为观察
5. 如果评分<60但有好叙事+大车头 → 可升级为关注（RH链上叙事权重应高于链上数据）
