# 营销主张验证 / Promo Claim Verification

用户会把加密圈的"爆款贴"转发过来（Grok Bot 收益截图、新币上线、开源项目、推荐码链接），
期待的不是"读起来像不像真的"，而是**先查到真实数字再评价**。

## 何时触发

- 转发带**收益数字**的内容：某人日赚 $X、24 小时 N 倍、累计 $Y
- 转发**新币/上线叙事**：交易所上线、发布会埋伏、空投
- 转发**工具/项目爆款**：AI 交易机器人、开源 agent、新框架
- 直接问句：**"真的可行吗" / "真的吗" / "这个方向值得关注吗"**
- 结尾带**推荐码/邀请链接**（`fomo.family/r/xxxx`、`t.co/...`）——最高优先级信号

## 用户风格（硬要求，别违背）

- **先证据后结论**。他明确要求过"先查链上或 API 的真实数字"——**不接受只从文本推理就下判断**。
- **结论先行**：第一段就给判定，证据放后面。不要铺垫、不要设问式开场。
- **给数字和命令，不给形容词**。每个判定挂一个可复现来源。
- **不说教、不写免责套话**。他讨厌表演式风险提示；他需要的是"哪部分没验证到 + 为什么"。
- 结尾给**可执行的下一步**（他能自己跑的验证、或我该写的脚本），不给"建议关注"式空话。

## 五步协议

### 0. 先锁定标的 —— ticker 不够，必须带链、带地址

同一个 ticker 在不同链上是**完全不同的东西**，验证错标的会让整个结论反掉。

> 实测事故：用户说「FTR 今天开发布会，昨天就该埋伏」。我按 **BSC 的 FTR** 验证 —— `flap_stocks`、
> MC $12.7K、无官网、被硬过滤器判死。他说的其实是 **Solana 的 FTR = Flying Tesla Roadster**
> （pump.fun、MC $5.5M、24h +981%）。两条链、两个币、结论相反，白跑一轮还差点给出反向判断。

- 用户只给 ticker 时：先 `curl "https://api.dexscreener.com/latest/dex/search?q=<TICKER>"`
  按 `chainId` 过滤列出候选，**要么在报告里显式写明「我查的是 X 链的 Y 版本」**，要么让他确认。
- **同名多地址是常态**（同链上常有第二个同名的克隆盘，MC 可能只有正盘的 1/5）——
  **地址级结论不跨地址套用**；买错那个就是另一个结局。
- 拿到 CA 后再进链上取数（见 `gmgn-onchain-analysis`）。

### 1. 拆主张
把帖子拆成**原子主张**。多数爆款混着三类东西，要分开判：
- 真实事件（上线、发布会确实存在）
- 夸大的数字（收益、涨幅、性能）
- 导流入口（推荐码、代币、工具链接）

### 2. 算术自检（最便宜，先做，不用联网）
- **内部一致性**：日收益 × 天数 = 累计？每笔均值 × 笔数 = 总计？
  - 实例：$508,183 / 125 天 = $4,065/天（自洽）；但"每小时 33 轮"= 792 轮/天，$4,065÷792 = **每轮 $5.1**，而它说"平均每笔 $258"→ 反推 15.8 笔/天 —— **两者差 50 倍，不可能同时成立**。
- **复利外推**：声称的倍率能维持几天？
  - 实例：223 倍/天 → 第 4 天超过 Jane Street 身家、第 5 天超过全球加密总市值 → **荒谬即证伪，无需任何外部数据**。
- **胜率必须配金额**：只给胜率（1871胜/35负）不给平均盈亏 = 废数据。套利本质就是"赢很多小钱、亏一次大钱"，不给金额的胜率等于什么都没说。
- **机制可行性**：跨 N 平台套利需要**每个平台预置库存**；$52 分 6 个平台 = 每平台 $8.7，还要扣提币费/跨链费 —— 每分钟 1.3 笔在 6 家之间搬运，**物理上不成立**。

### 3. 权威源验证
见下表与 `references/verification-recipes.md`（含可直接复制的 curl/jq）。

| 主张 | 权威源 |
|---|---|
| 某人赚了 $X（Polymarket） | `data-api.polymarket.com/v2/leaderboard?window=all&limit=500`（搜用户名/看 PnL）+ `/positions?user=0x…` |
| 某人排第几 / 交易水平（fomo.family 等社交交易 App） | `GET https://prod-api.fomo.family/v2/leaderboard`（实测 100 人，含 followers/numTrades；榜首 Unipcs）——需登录 cookie，方法见 `multi-platform-search-cli` 的 `references/authenticated-site-api.md` |
| "这个币正在热门" | `fomo.family 热门榜`（`POST /proxy/trendingTokens`）+ `gmgn-cli market hot-searches`，交叉看是否真在榜前列；若榜上无名而帖子说"爆火"，本身就是信号 |
| 代币上线时间 / 交易所 | 交易所公告页/API（Binance 公告、Bitget 支持页）+ **项目官方 tokenomics 文档**（常有 PDF，含 TGE 流通比例与解锁表） |
| 代币经济 / 流通量 | 项目官方文档（TGE 流通%、投资人与团队解锁表） |
| GitHub 项目是否存在 | 纯 HTML 状态码 + **控制组假仓库必须 404**（方法见 `multi-platform-search-cli`） |
| 产品声称的性能 | 仓库自身的 `docs/`、benchmark、README —— **官方文档的自我披露 > 营销摘要** |
| "AI 交易/量化能力" | **无权威源** → 只能验账号与算术，**能力主张一律标注"未验证"** |

### 4. 激励结构分析（往往一步定案）
- 结尾有**推荐码/邀请链接** → 他的收入来自拉人注册，**不是交易**。
- 带**自研代币**的工具（"扫描器"发自己的币、有自己 launchpad）→ 利益冲突，它靠你在它平台发币赚钱。
- **可复用判据：任何"多长时间多少倍 + 一个链接"的内容，它真正的产品就是那个链接。**
- 反向判据：真有稳定高收益策略的人**不会公开分享**（会自己加杠杆吃）。

### 5. 输出
判定（真 / 假 / 部分真）→ 证据（带数字与来源）→ **明确哪一块没验证到、为什么**。

## 本用户反复遇到的六类（先按这六类想）

1. **AI 交易收益神话**（Grok Bot / 量化机器人"日赚几千"）
   - 账户可能真实存在，**收益数字常差 1-2 个数量级**。实测：宣称 $508,183，实际 **$7,477**（差 68 倍）；且全站前 500 名没有任何人 PnL 落在被宣称的区间。
2. **新币上线叙事**（$DNA 之类）
   - 上线本身可验证为真，但**帖子常把时间/涨幅写错**（实测帖子写北京时间 8 点、官方文档 16:00）。
   - 结构风险要一起给：TGE 流通 13% + 6 家交易所同日 + 空投抛压 = 典型"上币即出货"窗口；**低流通意味着你的对手盘是零成本筹码**。
3. **开源项目爆款**（"200ms 决策核""速度与成本双杀"）
   - 仓库真、数字被加戏。实测三处失真：把**托管 API** 说成"本地决策核"（需 API key）；把**单次决策延迟 178ms** 说成"任务 200ms"；把**官方未公布的收费**说成"成本双杀"（官方文档明确写"TypeSafe 响应只给 token 数、不给计费金额"）。

4. **事件驱动埋伏叙事**（「XX 今天开发布会/上线，昨天就该埋伏」）
   - 这类**不是要他别信**，而是三条都要给出：**(a) 标的对不对**（ticker 跨链同名，见协议第 0 步）；
     **(b) 事件是否真实存在**（找官方账号/公告，别拿转发当证据）；**(c) 行情是否已经走完**。
   - **多数"该埋伏"贴是涨完才传到他手上的。** 实测 Solana FTR：24h **+981%（≈10x）**、
     24h 量 $21.4M（**=MC 的 4 倍**，明显叙事爆点）、**1h 已 −13%** → 事件当天就是
     「买预期、卖事实」的出货窗口，此时追进去是接盘。
   - 正确的结论方向：**承认他的判断对（这层逻辑确实缺），但把动作前移到「事件日历」**——
     下一次要在事件前 2-3 天看到，而不是事后复盘。入场逻辑和出场纪律是两套东西。
   - 附带提醒同名克隆盘：同链常有第二个同名地址（实测 MC 只有主盘的 1/5），买错就是另一个结局。

5. **转发的大佬访谈/认知长文**（"某某四小时对话总结"、人生建议、致富方法论）
   - 验证方法不同：这里没有可查的收益数字，要拆的是**叙事结构与利益位置**。
   - 三步：**(a) 把他的方法论对照他的真实路径**（实测：孙宇晨讲"零成本拼认知翻身"，但他真实路径是
     ICO 禁令前抢跑募资、收购买用户、控制交易所、身份对冲——把"时机+监管套利+资本"重定义成"认知"，
     这本身就是他的招牌手法"叙事覆盖"）；**(b) 区分抽象原则与个人约束**（"逐水草而居不被焊死"出自
     净资产 50-125 亿美元的人，机动性是他的特权；照搬给有家庭的人 = 风险不是自由）；
     **(c) 挑出真货**（"先自由后财富""钱是放大器、认知配不上就放大坏习惯""先侦察再下注"这类是真洞察，
     要明确指出来，别整体否定）。
   - 结论格式：**当营销方法论样本读有价值；当人生指南读会误伤自己**——因为那是写给高风险承受力人群的。
   - 若用户装载了对应的人物视角 skill（`*-perspective` 系列），停在**分析模式**，不要进入角色扮演：
     他要的是内容可信度判断，不是表演。

6. **新机制叙事**（"把挖矿塞进代币发行"、"零预留"、"可撤回预售"——如 TapeFour）
   - 这类不能一句"营销"打掉：**机制常常是真的新**，但价格位置往往是错的。必须三段分开答：
     **(a) 机制真伪**（是否改变供给释放方式或退出权）、**(b) 设计代价**（薄 LP 是内建属性，长期通胀是常态）、
     **(c) 现在的位置**（涨完才传到他手里）。
   - 完整五问 + TapeFour 实测数据（MC $2.05M / LP $81K = 25x / 6h +469%）+ 挖矿回本算式：
     见 `references/issuance-mechanism-eval.md`。
   - 结论模板：**机制值得学 ✅ / 现在该追 ❌，分开说**；真正好的参与点是下一个同机制项目的"可撤回预售"阶段。

7. **工具 / 生态 hype 帖**（"这个生态居然能自己长大"、连着甩五个 GitHub 仓库、插件套件推荐）
   - 这类最骗人的不是代码，是**"都在活跃维护"的暗示**。必须逐仓查两个字段：
     `stargazers_count` 和 **`pushed_at`**：
     ```bash
     gh api repos/<owner>/<repo> --jq '"\(.full_name) ★\(.stargazers_count) 更新\(.pushed_at[0:10])"'
     ```
     实测（2026-10，某 Hermes 生态推荐帖）：五个仓库全是真的，但**只有一个昨天还在推代码**，
     其余三个停更 3-4 个月。宿主迭代快 → **停更 3 个月的插件大概率装不上或跑不对**。
   - 带"自我进化 / 自我迭代"卖点的（agent 自己写 prompt、自己评估、自动多轮迭代）要问**谁付 token**：
     自循环多轮 = 每一步都是 LLM 调用。对成本敏感的用户，这不是能力增量，是**烧钱机器**。
   - 判断顺序：`pushed_at` > `stars` > README 承诺。**star 可以营销，commit 日期不会说谎。**
   - 安全面：Web 工作台 / 面板类（能开终端、读记忆、看技能）等于把执行面暴露给浏览器 ——
     必须只绑 `127.0.0.1` + 认证，否则是给泄露过的 key 再开一扇门。
   - 输出模板：分三档 **可以装 / 借鉴思路别装 / 别装**，每档一句理由，别只回"都是真的"。

8. **空投认领公告**（"X 月 X 日上线时开放认领"）
   - 这不是"信不信"的问题，是**安全 + 抛压**两件事，解读必须落到"别点错链接"。
   - **认领与 TGE 同日 = 抛压最集中**：所有人领完第一反应是卖，开盘 15-30 分钟定生死。
   - **官方那句「只用官网域名 / 忽略私信 / 绝不要私钥」是三重信号**：① 他们知道会有大量假站
     ② 空投确实有价值 ③ 认领窗口是**授权钓鱼（approve）高发期** —— 骗的不是私钥，
     是让你签一个"无限额度授权"（不花 gas、不弹私钥，很多人签完还不知道）。
   - 落地清单：只从**官网手输域名 + 官方 X 置顶**进；签名只该出现"领取"，遇到
     `Approve` / `SetApprovalForAll` / 无限额度一律拒绝；先确认自己地址有资格
     （没交互过别临时刷量，成本 > 空投价值）。常见假域名只差一个字母（`fables.fi` vs `fabels.fi`）。
   - 领到后怎么处置看机制：ve(3,3) 类是锁仓换 emissions / 手续费分成；不看好就别信"锁仓 APY 300%"
     （多数是通胀计价）。**空投是白捡的钱，不是信仰。**
   - **同名假币**：上线前搜到的 `<SYMBOL>` 且 `LP=$0` 的（哪怕显示 8 亿 MC）全是伪造盘；
     真币未发前，链上任何同名代币都不碰。

9. **直接丢一个仓库链接问「看看这个仓库」**（没有附转帖、没有收益宣称）
   - 这类最容易写成 README 复述。**判定锚点不是项目本身，是「他的实际战场」**：
     先说它在什么条件下有用，再说它在他的主战场（BSC/SOL meme CA）里为什么没用。
   - **meme 盘的价格由单一钱包/脚本决定，任何基于历史 K 线或价格序列的模型都不适用于它们。**
     面对「K线基础模型 / 预测涨跌 / 时序大模型」这类仓库必须主动把这句摆在前头，
     否则用户会以为能拿去查他每天发的那些 CA。流动好、多参与者的标的（BTC / 主流永续）才在能力圈内。
   - **成本要换算成「每天多少次 LLM 调用 / 多少钱」。** 新闻雷达/摘要类项目每条都要打分+摘要+富化，
     实测量级 100 万 token/天（DeepSeek 约 ¥1-2/天，GPT-4o 约 $5-8/天）。不换算，成本敏感的用户无法决策。
   - **star 不等于 edge。** 判断有没有用的是「有没有扣手续费的样本外结果」，不是 star 数或 demo 图；
     只有预测示例、没有回测曲线的，就是研究工件。
   - **上下文长度要换成他的时间尺度**：「512 根 K 线」要翻译成「1m 图 8.5 小时 / 5m 图 42 小时」，
     再说这个窗口和一个 meme 的生命周期比是长了还是短了。
   - 输出骨架（他接受的那版）：一句话定位 → 关键事实表（规模/许可/上下文/成本）→ **对你没用的地方（先说这个）**
     → 三个硬伤 → 可执行的验证方案（拿他现有系统当对照组 A，设「打不赢就扔掉」的判据）。
     不给「建议关注」这种空话。

## 收尾：指出"这是第几篇"

把单点结论升级为**投放模式**：实测用户在同一周内被投了三篇同构内容（Grok Bot 日赚 → AI Agent 叙事+新币上线 → Grok Bot 223 倍+推荐码），
结构都是「AI agent 叙事 → 夸张收益 → 一个你要点的入口」。

**告诉他这是同一波，比逐条驳倒更有价值。** 同时提醒：他的信息源（X 时间线）是**算法喂的、滞后**的——
这正是把 X 从"刷"变成"推"（`multi-platform-search-cli` 的 twitter-cli 账号监控）的理由。
