## 心智模型

### 1. 车头跟随（Wagon Tracking）
**核心逻辑：** 链上赚钱不是靠技术分析，是靠找到"车头"——有影响力的KOL/聪明钱正在进场的信号。
**证据：** "看到@0xSunNFT孙哥也加入$Hoodrat社区建设，好久没看到他出手了"——当他出手时，社区会跟随。
**应用：** 监控聪明钱和KOL钱包的进场时间，比看K线更有价值。
**局限：** 车头也会翻车，不能无脑跟。

### 2. 盈亏比优先（Risk-Reward First）
**核心逻辑：** 入场前先算盈亏比——如果亏了认不认，赚了能赚多少。
**证据：** "为自己认知买单，亏了也认了"——入场时已经想好了亏的后果。
**应用：** 只在盈亏比≥3:1时才入场。MC<$1M的早期标的才有足够上行空间。
**局限：** 盈亏比是静态计算，市场动态变化需及时调整。

### 3. 社区共识验证（Community Consensus）
**核心逻辑：** 一个币有没有价值，看社区有没有真人在做事，而不是看价格。
**证据：** 参与$Hoodrat社区建设而非纯投机——链上KOL投的是社区共识。
**应用：** 评估一个币时要看：社区活跃度>KOL喊单>链上数据>价格。
**局限：** 虚假社区（刷评论/机器人大军）难以区分。

### 4. 链叙事映射（Chain Narrative Mapping）
**核心逻辑：** RH Chain的叙事会重演Solana/BSC的历史——如果Sol上的某个叙事火了，RH上一定会出现对位版本。
**证据：** RH链的CASHCAT/$Hoodrat/$JUGGERNAUT叙事结构，与Solana上的meme生态高度相似。
**应用：** 看到一个链上的新叙事，立刻去其他链找还没被发现的镜像版本。
**局限：** 跨链叙事的时间窗口越来越短。

## 决策启发式

1. **如果MC<$1M+聪明钱>5+社区有真人** → 可以小仓位试
2. **如果发现车头（KOL/聪明钱）在进场但还没发推** → 优先于他们发推前进场
3. **如果已经涨了3-5倍还没找到接盘叙事** → 分批止盈，不贪最后一个铜板
4. **如果币价跌了但社区还在建设** → 可以加仓，这是"为自己认知买单"
5. **如果KOL开始批量喊同一个币** → 说明窗口快关了，准备跑
6. **如果RH链上出新叙事，先去Solana找原版** → 确认叙事是否已被验证
