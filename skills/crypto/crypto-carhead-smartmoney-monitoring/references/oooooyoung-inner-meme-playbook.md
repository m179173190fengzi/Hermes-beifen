## 实战篇 11 条（原文顺序，压缩）

0. 围绕**推文热点**玩，随行情切换对象：BSC 火 → cz / heyi / 币安官推；SOL 火 → 马斯克 / 特朗普 / toly / sol 官推；Robinhood 火 → vlad。
   （2026-09 更新：币股 meme 时代要盯**各个底池的官推 + 创始人推特**，出一个新底池就搞懂它是什么、官推是谁。）
   PS：每个火起来的 meme，都去里面搜集「盈利最多 + 进得最早」的几个钱包，**扩充自己的聪明钱库**。
1. **一眼塞**：盯战壕页新创建列表。看到官推/名人发推，**先总结推文最有角度的一个词儿，再去找第一个正确的盘**（不是盘出来了才想角度）。
   无名人发推时盯新盘，且要看每个新币的社媒链接内容，判断这个推文/抖音/网站会不会火。
   选盘法则：同名多盘 → 图片偏 meme + ticker 正确 + 台子正确的第一个；行情一般 → 优先"最先 Dev Sell"的；有底部老盘也可上。
2. **永远不要在没涨时认为它起不来，也永远不要在涨的时候上车**。买之前想：KOL/车头会不会买？会买就上，不会就别买。
3. 看到但犹豫了（角度好）→ **等一根红线砸下来再上车**；有内盘车头上车要看 K 线有没有量，有量第一时间上。（翻倍出本）
4. meme 分两类：**PVP 浇给型**（赚了就跑）vs **发酵型**（出本长持）。必须能判断是哪种。
5. 行情好：塞入 **30 秒**没起来直接 sell。
6. 行情坏：只上叙事好的长持。
7. 不听喊单（除非胜率很高的车头/博主）。
8. 摒弃普通人思维，切交易员思维，适度追涨杀跌。
9. 知行合一，尊重第一念头。找个靠谱群聊，乱发 CA 的群直接退。
10. 要有"这个 meme 会不会掀起新热潮"的预感——**长拿只拿龙头**（AI 波只拿 GOAT、中文叙事只拿币安人生）。
11. 只做自己的车头，上车要自信，让车头来抬你；多复盘车头的买卖点但别跟单车头。
