# 中文圈 车头 / 聪明钱地址监控 方法论

面向两类任务：(A) 调研中文币圈「车头/大车头钱包/聪明钱监控」玩法并产出报告；(B) 设计或审查聪明钱/共识买入监控系统。

## 触发条件

- 用户问「中文圈怎么用聪明钱/车头监控打狗」「车头是什么」「怎么提高 meme 胜率」。
- 用户要设计/改进「监控某几个钱包买入 → 共识信号」这类监控（尤其 FOMO 标签钱包）。
- 需要中文 meme 交易术语、仓位纪律、骗局清单。

## 核心术语

- **车头**：链上地址被大量交易者监控、买卖能带动盘面的大户。跟买叫**上车**，砸盘/亏钱叫**翻车**。
- **反向车头 / 假车头**：车头知道被监控后故意做反向信号收割跟单者（最大坑）。
- **跟单砸盘出货**：明牌自己地址、大单买入引跟单，再用别的钱包出货。
- **老鼠仓**：用未公开信息提前低价建仓，消息公布后卖给追进来的人。
- **接最后一棒**：KOL/车头自带跟单流量，你买进去时往往就是最后一批流动性。
- 其它：土狗/RUG/内盘外盘/扫链/刮刀/CA/夹子/貔貅盘/撤池子/捆绑盘。

## 主流玩法（4 类，中文圈共识=组合使用）

1. 跟随车头/聪明钱（GMGN 牛人榜、OKX 追踪、Ave.ai、Debot）——**只作信号参考，不跟单车头**。
2. 多钱包共识警报（分组设「X 钱包/多大金额/多久内买同一币」规则推送）——**多钱包行为 > 单钱包跟单**。
3. 自己扫链 + 建地址库（按 KOL/金狗捕手/庄/老鼠仓分类，每天枯坐 10h+）。
4. 组合：扫链发现 + 聪明钱验证 + 舆情 + 合约安全核查 → 才下单。

## 关键纪律与数字（提高胜率）

- 仓位：**3+2 仓位法**（3 笔小仓 5–10% + 2 笔中仓 10–20% + 现金 ≥40%）；低市值总持仓 ≤ 币量 5%；多钱包分散 **2:3:5** 或 **1:1:2:2:4**；固定**比例**而非固定金额。
- 止盈：**2x 出本 → 3–5x 卖 50% → 10x+ 分批卖 90%+**；「翻倍出本」。
- 止损：**30 分钟无交易量即卖**；rug 信号立即清仓；入场理由证伪不计价止损；常用 -50%。
- 概率：ETH 土狗胜率 ~3.28%、SOL ~1.6%；复盘目标胜率>35%、盈亏比>3:1、单笔回撤≤总仓 20%。
- 时机：不追涨、不在没涨时看空；小叙事日内跑；大 KOL 喊单后 1–2 天常是出货窗口。

## 常见骗局 / 亏钱原因

追高接棒 · 跟买不跟卖 · 反向车头 · 老鼠仓捆绑盘（GMGN 持有者一片红）· 貔貅盘（Rugcheck 查 Sell Tax 100%）· 撤池子（须 100% 锁仓 3–6 月、凭证进黑洞）· 盗号盘 · 空白官推+非原创图 · 合约漏洞（ETH 无漏洞合约仅 ~2%）· 夹子 MEV · 群内情绪。

## FOMO 钱包事实（设计 FOMO 监控必读）

- GMGN「**Fomo 喊单**」= FOMO 帖子，**发帖必须正持有该币，仓位自动附帖**；「**Fomo Top**」= FOMO **头部钱包**资金动作。头部钱包名单来自**第三方 FomoScan**（口径=已实现盈亏 + 最少完整往返次数 + 成交额门槛）。
- ⚠️ GMGN **未公开**取哪份名单/时间窗/名次。
- ⚠️ **Fomo Top 的「转入」≠「买入」**（跨链 Relay 无法区分转账/交易，可能是投毒转账）。要区分买卖用**聪明钱**标记。

## 监控设计 Checklist（把「共识买入」做扎实）

1. 排序补「最少完整往返次数 + 成交额门槛」，排除单笔暴赚的老鼠仓。
2. 共识窗口**分层缩短**（时间衰减）：24h 内≥2=强、6h 内≥2=极强；>24h 降权。
3. 加**价格位置过滤**：现价已比最早共识买入价高 10–20% → 信号已过，不追。
4. 监控买入**同时监控卖出/转出**（跟买也要跟卖）。
5. 区分「转入 vs 真买入」，过滤投毒/被动转账。
6. 做**关联地址分析**，把「关联钱包共识」降权（识别抱团出货），只信「独立钱包共识」。
7. 叠加**币本身硬过滤**：锁仓、Top10 占比>50%、dev 持币、合约安全、持有者是否一片红。
8. 信号只触发**小仓试探单**（总仓 5–10%），落地翻倍出本/-50% 止损/30 分钟无量即撤。
9. 保留「叙事/背景」人工复核入口——高倍来自背景+新叙事，钱包共识只是择时。

## 角度先行（比"扫到再编叙事"高一层）

中文圈实盘打法的共识操作顺序是反直觉的：

1. 盯**官推/名人/车头**的推文（BSC → cz / heyi / 币安官推；SOL → 马斯克 / 特朗普 / toly；币股 meme → 各底池官推 + 创始人）。
2. **先从推文里提炼一个"角度词"**（最有 meme 感的那一个词）。
3. **再去找第一个"角度与词最贴合"的盘**——而不是先有盘、再回头硬编叙事。

顺序颠倒的代价是可观测的：先扫盘再编故事，会漏掉真正的事件驱动盘（盘刚出来时结构指标必然难看，会被过滤器判死）。
所以做日报/推荐时，正确输出形态是 `叙事 → 角度词 → 最贴合标的（+次选）`，不是 `标的 → 叙事`。

配套的现象：同一个叙事会同时冒出多个同名盘，选盘优先级是「图片偏 meme + ticker 正确 + 台子正确」，
行情一般时优先"最先 Dev Sell"的盘；1–2 M 级别以上的盘出来后，去抓它的**衍生盘底部**而不是追主盘。
