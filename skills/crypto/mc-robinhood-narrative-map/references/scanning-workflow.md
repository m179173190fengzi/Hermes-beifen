# Robinhood Chain 扫链全流程

> 用户编写的完整扫链流程，适用于Robinhood Chain新币发现。

## 监控页面

- DexScreener Robinhood New Pairs
- NOXA Fun Trending

## 筛选步骤

1. **实时刷新**，关注年龄 < 30分钟的新对
2. **快速筛选三个问题**：
   - 有无社交链接（Twitter/TG）？
   - 叙述是否强（Robinhood/GME/官方相关）？
   - 交易量和买入笔数是否突破？
3. **深入分析**：
   - 通过 BasedBot/GMGN 或 DEX 买入（小仓位测试）
   - 持续监控：持仓分布变化、聪明钱动向、流动性
   - 分批止盈/止损

## 购买检查清单（按顺序）

1. **年龄**：< 30分钟（太老机会小）
2. **叙述**：搜 X「$币名 Robinhood」有没有热度？（GME/猫狗/官方相关最好）
3. **数据**：交易量上升+买入多；持仓数快速增加；市值低（早期几万~百万美元）
4. **链上查**：复制CA → Blockscout（https://robinhoodchain.blockscout.com）看Top10是否太集中、创造者有没有狂卖
5. **GMGN确认**：聪明钱有没有买？有没有地毯警告？
6. **只买小仓**：先买总资金1-2%测试
7. **立即回避**：开发者持续抛售、持仓极端集中或狙击手束、无社交/叙述、流动性可随时移除、蜜罐或高税费

## 卖出与风控

- 止盈：涨2x卖30%、5x卖30%、10x卖剩余
- 止损：跌50%坚决卖
- 分散：同时看3-5个币

## 日常监控

- 每天固定刷Dexscreener + NOXA Fun
- 加X搜索提醒："Robinhood Chain memecoin" 或具体币名
- 复盘：每笔交易记笔记
- GMGN跟单聪明钱、设置价格警报

## 潜力币判断

**看谁发起的（GMGN可查）：**
- 创建者钱包部署了多少合约？
- 之前的发射成功了吗？
- 流动性消失了吗？
- 创建方是否立即售出？
- 这个钱包每天不断创造新币吗？

**流动性是关键：**
- 新币A：MC $100万，Liq $10万
- 新币B：MC $60万，Liq $30万（更有价值）
