## 0. 先纠正一个前提：平台标签 ≠ 聪明钱标签

GMGN 的 `fomo`（以及 `gmgn` / `axiom` / `photon`）是**平台使用标签**，只说明"这个地址用过哪个 App"，
**不代表资金来源，也不能推断这些地址属于同一批资金**。实测口径：某代币前 100 名持有者里
**42 个带 fomo、17 个 gmgn、1 个 axiom**；前 100 名交易者里 45 个 fomo。
→ 平台标签是**上万人的大集合**，过滤度极低。它只能用来建候选池，**筛选必须靠钱包质量指标**。
来源：https://gmgn.ai/blog/what-to-check-after-finding-a-trending-memecoin/

补充机制：GMGN 图表上的 Fomo 标记来自第三方指数 **FomoScan**（GMGN 声明与其无关联），
榜单按已实现 PnL 排名并设有**最小 round-trip 与成交量门槛**——但 GMGN 未公开取哪个窗口。
（注：实测 `fomoscan.io` 是 GoDaddy 停放站，`fomoscan.ai` 无相关内容——不要把它当成可取数的 API。）
来源：https://gmgn.ai/blog/how-to-read-fomo-calls-on-gmgn-chart/

## 1. 选钱包：阈值与反例

| 指标 | 建议阈值 | 来源 |
|---|---|---|
| 7 天胜率 | **50–90%**（缺好钱包时放宽 40–90%；shitcoin 里 >50% 已属不错） | r/CryptoTrenching |
| 更严实盘样本 | **70%+ 胜率 / 50+ 笔**（有人花 $5k 扫 1 万钱包，只筛出约 100 个真钱包） | r/SolanaMemeCoins |
| 交易样本量 | **7 天 ≥100 笔**（区分活跃真钱包 vs 几笔高胜率的刷单小号） | r/CryptoTrenching |
| 平均持仓 | 避开**秒级**进出（GMGN 的 Phishing 检测会标记 **5 秒内买卖**） | gmgn.ai blog |
| 仓位 vs 池子 | 钱包单笔相对池子要**小**；常年吃掉薄池子很大比例的，跟单者就是它的对手盘 | memecentral.fun |
| 记录稳定性 | **7 天 vs 30 天并排看**；只在最近几天赚钱 = 可能只是热手；"去掉单笔最好交易后仍成立"才采用 | gmgn.ai / memecentral |
| 资金去向 | 拒绝与**代币部署者共用同一个 CEX 子账户/桥**的钱包（≈内部人） | r/SolanaMemeCoins |

**反例（最有力的证据）**：对 kolscan 自报 KOL 钱包的统计——**30 天榜前 50 名，输的交易比赢的多**；
中位胜率 1 天 43% / 7 天 43% / **30 天仅 34%**，且 30 天期 **72%** 的钱包胜率低于 50%，中位交易数 1375 笔。
来源：https://accompli.sh/research/onchain-memecoin-trading-study/

**为什么"按已实现盈利排名"是循环论证**：排名用的度量本身就是被拿来当证据的东西——
排行榜天然奖励"自己控盘的假市场"和高频刷量。原文：*"A win rate is an output, not evidence."*
自导自演套路：自己发币 → 自己持大部分供应 → 让"展示钱包"早期买入 → 用隐藏钱包拉盘，
让展示钱包显示惊人浮盈；重复十几个币，链上每笔都真实、每个市场都是假的。
来源：https://dev.to/verixia_233e4721792ce3390/how-copy-trading-rugs-work-when-the-wallet-you-follow-is-the-trap-198n

实操推论（本会话实测印证）：按 `realized_profit` **绝对值**排序会把**刷量机器人**排到前面——
实测 BSC 池 rank #2 是 30 天 +$2,735（**收益率仅 +1.09%**）、成本 $291,022、交易 1,941 个币种的高频账户；
小池子里尾部甚至可以是净亏损钱包。应用 `realized_profit_pnl` + `winrate` + `token_num` 复合判断。

## 2. 跟单时机：延迟吃掉多少利润

- **现实延迟 10–30 秒**。
- 新盘**首 30 秒常涨 3–5 倍**；**头 10 秒入场赚钱，1–10 分钟窗口亏得最多**；**晚 60 秒即使用过滤器也做不成盈利**。
- 推论：**薄池子不跟**（< $50k 流动性时你的 10–30 秒延迟会把入场价推到 3–5 倍）。
  这是"只跟流动性 ≥$50k 的币"这条规则的真正理由。

## 3. 共识/集群信号：窗口与钱包数

| 工具/来源 | 参数 |
|---|---|
| Reign（集群警报）默认 | min **2** 钱包 / **1,440 分钟**；可选 2/3/4/5 × 15m/30m/1h/6h/12h/24h |
| Reign 推荐配方 | 跟踪 <20 钱包 → **min 2 / 24h**；20–100 → **min 3 / 6h**；100+ 高频 → **min 4 / 1h**；**Solana meme 专用 min 2 / 30m** |
| Nansen | **10+ 聪明钱 / 48 小时**（面向更大市值、更慢节奏） |
| 开源集群检测器 | `min_wallets=3, window=15min`，按钱包评分加权而非简单计数 |
| RugSniffer | **2 个**"历史早期命中率 ≥50% 且不 scalp"的钱包进入同一新盘 |

**结论：meme 场景下"≥2 钱包 / 48h"偏松。** 48h 会把"今天买 A、明天另一个人也买 A"这种弱关联算成共识。
meme 建议 **2–3 钱包 / 30 分钟**；窗口越短钱包越多 = 信念越强但越安静。
来源：https://docs.reigntracker.com/features/cluster-alerts/ 、
https://nansen.ai/post/how-to-track-solana-wallets-complete-guide-for-smart-money-analysis

**共识可被伪造——必须验证钱包独立性**：同一时间创建的钱包、相同资金源、同一批代币同步买卖、
卖出利润回流同一归集地址 = 一个实体。同理"多个钱包同天被创建 + 只交易单一代币 = 协同而非独立"。
若关联集群控制某币 **20%+ 供应**，风险显著升高。
来源：https://defade.org/blog/solana-memecoin-insider-networks

**资金源关联比 bundle 更能识别抱团**（MELT 数据）：同一笔交易内多账户买入覆盖 **9.16%** 供应；
**共享资金源 28.22%**；共享 Jito bundle ID **15.96%**；合计 **36.5%**。
→ **低 Bundle% 不等于筹码干净**，必须配资金来源检查。
来源：https://gmgn.ai/blog/what-is-a-meme-coin-bundle/

## 4. 过滤器：哪些真的提高命中率

**GMGN Trenches 默认线（可量化基线）**：Top10 持币 **30%**、DEV **30%**、Insiders **5%**、
Phishing **5%**、Bundlers / Fresh / Sniper / Rugged 各 **10%**；Burnt **100%** = 项目方无法从池子提款。
⚠️ 这些是**默认筛选线不是安全承诺**，且 Top10 只覆盖 10 个地址——真正要看**前 100 名累计占比**与资金来源。
来源：https://gmgn.ai/blog/what-to-check-after-finding-a-trending-memecoin/

**同一份回测（数字是硬证据）**：

| 特征 | ≥$30k 峰值率 | ≥$100k 峰值率 |
|---|---|---|
| 无 Twitter | 0.9% | **0.5%** |
| **有 Twitter 主页** | **7.2%** | **3.6%** |
| 只有一条推文链接 | 1.0% | 0.5% |
| 有官网 | 5.0% | 2.7% |
| **无官网** | **0.3%** | **0.0%** |
| **连环发币者（窗口内 ≥3 次）** | **0.4%** | **0.0%** |
| 单次发射者 | 5.0% | 2.7% |

→ **每一个 100k 峰值都来自"窗口内发射 <3 次"且"元数据里有官网"的创建者**；
叠加"非连环 / 非克隆 / 有官网"后 **100k 峰值率从 2.2% 抬到 15.2%**（样本 273 → 33）。
⚠️ 反直觉：bundle/sniper 在**跑出来的币上出现得更多**（跟着注意力走）——bundle 是"你在跟谁付钱"的警告，
不是"这币会失败"的证据。来源：https://accompli.sh/research/onchain-memecoin-trading-study/

**连环发币者风险的独立佐证**（USENIX Security 2023）：BSC 上 **1% 的地址创建了 24.3% 的代币**（ETH 20.1%）；
BSC 4,231 个"代币垃圾制造者"里 **50% 至少做过一次 rug**；该数据集约 **60% 的代币活不过一天**。
来源：https://gmgn.ai/blog/what-to-check-after-finding-a-trending-memecoin/

**流动性与币龄阈值**：流动性 **<$10k 不是"早期"而是结构性脆弱**（几个钱包就能双向大幅拉动）；
Gemini 系工具口径：**<$50k = HIGH RISK**、**成交量/流动性 > 5x = 潜在操纵**、
币龄 **<24h 极高风险 / <7d 高风险（多数 rug 在此阶段）/ >90d 较低风险**。

**蜜罐模拟必须买+卖两步**：BSC/ETH 用 GoPlus / honeypot.is 做**买卖双向模拟**（见
`references/eleven-point-token-scorecard.md` 的接口字段表）；带卖前模拟器的执行端实测拦截更优
（90 天实测 Banana Gun 拦下全部 4 个蜜罐，Trojan 执行了 2 个、BullX 3 个）。

## 5. 退出纪律（多来源互证）

- **仓位**：单笔 **1–2%**（按 2% 计需连亏 50 次才爆仓）。先定仓位再定止损。
- **止损按入场规模反推，没有通用百分比**：蓝筹低风险 **-20%**，新叙事低市值 **-80%**（meme 常见）；
  TreadeLabs 模板统一 **-40%**；RugSniffer 纸面 **-30%**。
- **止盈阶梯（最广泛互证）**：**2x 卖 50% 收回本金 → 5–10x 再卖 25% → 剩余 25–35% 挂移动止损**。
  变体：2x 卖 25% / 4x 再卖 25% / 剩 50% 移动止损；RugSniffer +50%/+100%/+300%。
  所有出场**在开仓前就设定好**。
- **移动止损宽度**：15–20% = scalp 低信念；**25–35% = 大多数 meme 的甜点区**；40–50% = 高信念吃主升浪。
- **时间止损（最被低估）**：动量论点失效 = 价格不扩张 + 成交量衰减 + 叙事热度流失。
  预设最大持有窗口（**12h / 24h / 3d**），窗口内无预期扩张即离场，不要等价格确认。
- **出场必须独立于被跟钱包**：用自设 TP/SL（关闭 follow-selling）——你的卖单必然晚于它、砸在它压低的簿里。

## 6. 跟单的结构性陷阱

1. **持有期错配**：被跟钱包中位持仓 **18 小时**（或数天）；跟单者按自己的时间表出场拿不到这份战绩
   （KOL Explorer 页面原文即警告此点）。跟它的买点就得用它的持有逻辑，否则-30~-40% 的正常回撤会把你震出去。
2. **收益不可复现**：*"没有公开数据集说明跟单者实际赚了多少，因此没人能用数字诚实回答"*（memecentral）。
3. **反向车头**：钱包被大量监控后**故意做反向信号**；跟单砸盘出货；老鼠仓。
4. **转入 ≠ 买入**：`transferIn` 可能是投毒转账，跨链 Relay 无法区分转入与买入——买入信号只用真实 swap 记录。
5. **只跟买不跟卖**：必须同时监控卖出/转出，否则币被派发时你还在跟买。
