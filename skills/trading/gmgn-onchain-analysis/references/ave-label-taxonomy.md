# Ave 标签语义速查（四层对象 + 五个误读陷阱）

来源：Ave PC 端标签说明（用户 2026-10 提供原文）。Ave 与 GMGN 是互补工具：
**Ave/GMGN 标签回答「谁在参与、发生了什么」，GoPlus 回答「我买了能不能跑出来」。**

## 核心原则：四类标签描述的对象不同，不能混读

| 类别 | 回答的问题 | 典型标签 |
|---|---|---|
| 代币画像 | 这个币**怎样被归类** | 币安Alpha、金狗榜、潜力榜、垃圾池子、跑路(Rug Pull) |
| 地址画像 | 这个钱包**有什么特征** | KOL、KOL同车、DEV、DEV小号、巨鲸、聪明钱、老鼠仓、阴谋集团、纸手/钻石手、彩票流/热点流 |
| 数据与信号 | **发生了什么 / 统计了什么** | DEV买入/卖出/加仓/减仓/清仓/转入/转出/销毁、DEV加流动性/减流动性/烧池子/单边流动性、KOL喊单/买入/卖出、暴涨/暴跌、高换手、CTO、大额买入、Top10持仓占比、聪明钱买入次数 |
| 发射平台 | 这个币**来自哪个平台** | Pump.fun(SOL)、Flap(BSC)、Four.meme(BSC) |

同一地址可同时带多个画像 —— 标签描述的是**不同维度**，不是同一件事。

## ⚠️ 五个最容易误读的坑

1. **「钓鱼钱包」≠ 黑客钓鱼**。Ave 口径描述的是「其他地址**转入**当前代币」→ 通常代表**筹码分发**。按字面理解全错。
2. **「FOMO」是平台来源标签**（fomo.family 交易 App），**不是聪明钱标签**。GMGN 的 `fomo` 标签同理 —— 只说明"用过这个 App"。GMGN 官方博客佐证：某币前100持有者里 42 个都带 fomo 标签。
3. **次数 ≠ 独立地址数**。「聪明钱买入次数」是 24h 统计，一个地址买 5 次算 5 次；判断共识强弱必须数**独立地址**（同 Nansen 提醒：多钱包同天创建、只交易单一代币 = 协同而非独立）。
4. **Top10 占比已剔除池子/黑洞地址**。所以不能与「某地址占 77%」这类裸数据直接对比 —— 那个 77% 往往就是 launchpad 池合约（`addr_type=2`）。本 skill 的 pitfall 表有对应条目。
5. **CTO（社区接管）的前提是原团队已经跑路**。它是"死而复生"标签，本身不是加分项 —— 要看接管后的社媒更新与新资金进场。

## 其他需要记准的语义

- **新开户**：相对于**当前代币**的首次买入（不是新钱包）
- **DEV 小号**：识别口径是「开盘区块买入」，控制关系仍需额外证据
- **DEV 单边流动性**：只加当前代币一侧 → 文档明示**可能存在出货嫌疑**（实用风险信号）
- **DEV 烧池子 = LP burn**（销毁 LP，池子锁死）；**DEV 销毁 = 代币打到黑洞**（减少全流通量）。两者**作用对象不同**，别混
- **DEV 转入/转出** ≠ 买卖；**转账和买卖必须分开读**
- **KOL 喊单**（X 上发声）≠ **KOL 买入**（链上成交）≠ **KOL 同车**（当前持仓状态）—— 三个不同的东西
- **暴涨/暴跌**：过去 **15 分钟**幅度大且交易活跃（阈值因链而异）
- **高换手**：过去 **24 小时**筹码换手率高
- **潜力榜**：开盘后 30 分钟的中小市值，条件含 DEV/老鼠仓占比低、24h 涨幅与活跃度较好、未破发
- **金狗榜**：综合市值、持币人数、流动性、交易活跃度、近期相对涨幅、盈利地址占比、风险筛除
- **榜单是筛选结果，不是安全承诺**；**发射台标识不代表安全等级或涨跌**

## 操作化：下单前四层标签交叉检查

1. **来源层** — 什么发射台（Flap / Four.meme / Pump.fun）→ 决定套哪套过滤标准
2. **地址层** — 有没有 DEV小号 / 老鼠仓 / 阴谋集团 / 钓鱼地址(分发) → 控盘与出货风险
3. **事件层** — 有没有 DEV 加/减流动性、**单边流动性**、烧池子、清仓 → 最实用的动作信号
4. **统计层** — Top10（剔池后）+ 聪明钱**独立地址数**（不是次数）+ 换手率

## 与本 skill 工具链的对应

| Ave 标签层 | 我们的数据源 |
|---|---|
| 地址画像（DEV/老鼠仓/围猎） | `gmgn-cli token info --raw` → `stat.top_rat_trader_percentage` / `top_entrapment_trader_percentage` / `dev.creator_open_count` / `dev.creator_token_status` |
| 统计层 Top10 | `stat.top_10_holder_rate`（GMGN 口径同样已剔池） |
| 事件层 DEV 动作 | `token holders`（`addr_type=2` 池合约识别）+ `portfolio activity`（`--type buy/sell`，注意 `tx_hash` 字段） |
| 硬安全结论 | GoPlus `token_security/56`（新盘可用）；honeypot.is v2（老盘可用、新盘 404） |
