# 扫描与监控纪律（用户偏好，实测边界）

这份文件管的是「扫到东西之后怎么呈现 / 什么时候该持续盯」——不是 API 用法。

## 1. 默认不盯任何币（用户明确要求，2026-10）

> 「以后我发 ca 我说要你盯才开始盯」

触发**单币持续监控**必须**同时**满足两条：

1. 用户主动发 CA
2. 用户明确说「盯」

缺一不可。**只发 CA = 一次性体检**（结构 / 叙事 / 风险 / 值不值得打），不要顺手建监控任务。
用户说「这个币不要盯了」→ 清空 `~/.hermes/cron/watch_prices.json`（写 `[]`）+ 暂停价格告警 cron，
并回一句"以后发 CA + 说盯 我才启动"。

监控脚本形态：`price_watch.py` + `watch_prices.json`
（规则：`mc_below` / `mc_above` / `lp_below`），no_agent cron，**越线才响、平时 stdout 为空**，
条件解除后自动重新武装。**提醒 ≠ 买点**——越线只代表"该看看了"，还要确认企稳 + LP 已锁。

## 2. 角度先行（顺序铁律）

**先提炼角度词 → 再找最贴合标的**；禁止先列标的后编叙事。

- 角度词 = 能**直接当 ticker / 图片梗**用的那个词（例：FTR 那波的「能飞 / roadster」）
- 选盘判据：贴合角度词 + 台子正确 + 图片梗对 + 结构干净
- 报告输出固定顺序：`🔑 角度词` → `🎯 最贴合标的`（symbol + CA + 一句贴合理由）

反面教材：先扫盘再想叙事 → 等看到盘时已只剩追高（FTR 24h +981% 之后 1h −13%）。

## 3. 盘型二分：PVP vs 发酵（决定离场方式）

| 类型 | 特征 | 离场 |
|---|---|---|
| **PVP（浇给型）** | 抢热度、无持续催化、同名盘内卷 | **赚了就跑**（行情热时 30s 不起直接 sell） |
| **发酵型** | 有持续内容/事件输出（电影、MV、IP、官推节奏） | **翻倍出本**（本金先撤）后长持 |

判不出类型 = 不该开仓（离场规则无法预先确定）。输出时标出来，不要只给数字。

## 4. 批量扫描的硬门槛（从 trenches 字段实测校准）

用 `market trenches` 的富字段做扫描时，这几条门槛是**用真实数据校准过**的：

| 门槛 | 值 | 原因 |
|---|---|---|
| LP | **≥ $10K**（不是 $30K） | SOL 未迁移的 pump/flap 币 LP 天然很小（$0-28K），按 $30K 会把整链扫空 |
| Top10 | ≤ 50% 直接淘汰；≤ 20% 才算健康 | 50% 以上是明牌控盘 |
| 围猎盘 entrapment | > 30% 淘汰 | BSC 系统性问题，15-60% 常见 |
| bundle | > 40% 淘汰；≤ 15% 健康 | — |
| 持币 | ≥ 200 淘汰线，≥ 300 健康 | — |
| 24h 量 | ≥ $50K | 无量的"MC 达 $1M"是假达标 |
| dev 发币数 | < 5 健康 | 连环发币者等于抽水机 |

**同名去重是必须的**：同一 symbol 会出现多个 CA（仿盘/多链克隆）。
去重按 symbol 保留**评分最高**的那个，否则 SOL 一轮能刷出上百个"候选"。
同时要提醒用户：多链同 ticker 泛滥时**只买主盘那个 CA**（DexScreener 搜索一次能看到 30 个同名）。

**新币段（1D 内 + MC≥$1M）额外门槛**：持币 ≥200 且 24h 量 ≥$50K，否则会出现"MC $1M、持币 104、量 $1.5K"的假达标。

## 4.1 「老盘迁移」不是新开盘（币龄字段会骗人）

实测：某 SOL 盘 `币龄 17370h`（约 2 年）却在当日 05:36 才"开盘"，MC 小、看着像新币低吸机会 ——
其实是**老盘迁移/换池**（trenches 里 status 变 2 / 换台子重新开盘）。

识别组合（满足两条以上就按老盘处理）：

| 信号 | 含义 |
|---|---|
| 币龄数千小时以上 + 今日开盘时间 | 老盘迁移，不是首发 |
| LP 极薄（<$20K）且未烧/未锁 | 随时能抽，迁移常见套路 |
| TW/官网字段是**社群链接**（`i/communities/…`）或单条推文 | 无真实项目主页，伪装喊单 |
| 持币数极大（万级）但人均持仓市值 <$2 | 批量分发/拉群撑数 |

处理：报告里必须**明写"老盘迁移"**，并按 LP 未锁的老盘风控 —— 不能因为"刚开盘、MC 还小"当新盘打。
教训：满分评分（如 83 分、聪明钱 16）**不覆盖**这个结构风险，评分高 ≠ 能进。

## 5. 输出自检

摘要里带一行计数：`过线 N 个｜硬门槛淘汰 M｜去重后 K`。
某链出现 **0 候选**时，**先怀疑限流/网络**（见 `gmgn-cli-field-quirks.md` 的 429 一节），
不要直接下"今天没有机会"的结论——限流会把整批候选变成空。
