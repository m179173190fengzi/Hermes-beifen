# BSC 市场情绪阶段分析框架

## 三阶段模型

BSC 上的 meme 币炒作有明显的 **三阶段周期**，检测当前阶段可以避免在错误的时间追涨：

### 阶段1：CZ 狂潮期（CZ Frenzy）
**特征：**
- 每5~15分钟就有新 CZ 相关代币进入热搜
- Buy/Sell 比率 > 2.0（买盘压倒性）
- 多个 CZ-xxx 代币同时挺进前20
- 有新鲜币（age < 2h）持续冲入排行榜
- 成交量集中，TOP3 代币占总成交量 > 60%

**操作建议：**
- 找低市值（MC < 50K）+ 高分散（Top10 < 20%）的 CZ 新币
- 小仓位快进快出
- 龙头 $CZ 有第二波机会

### 阶段2：冷却过渡期（Cooling / Wait-and-See）
**特征：**
- 没有新鲜币冲进前20（0个 age < 2h）
- Buy/Sell 在 1.0~1.3 之间（市场犹豫）
- CZ 龙头在回调（-5% ~ -15%）
- 小市值代币冒头但还没形成气候（如 OMAR、LMEOW）

**操作建议：**
- **不要追高** — 市场在等下一个叙事
- 观察龙头 CZ 的价格支撑位（如 $0.02 是否撑住）
- 等待阶段3的信号

### 阶段3：叙事真空期（Narrative Vacuum）
**特征：**
- 没有明确的主导叙事
- 交易量萎缩到正常水平的 30% 以下
- Buy/Sell ≈ 1.0（多空平衡）
- 所有人都跑去 Solana 了

**操作建议：**
- 别碰 BSC，关注 Solana 的热点
- 等下一个 Solana 热点出现 → 预测 BSC 会抄谁
- 提前埋伏 CZ 版本的代笔

## 快速判断指标

| 指标 | 狂潮期 | 冷却期 | 真空期 |
|:----|:-----:|:------:|:------:|
| Buy/Sell Ratio | > 2.0 | 1.0~1.3 | ≈ 1.0 |
| 新鲜币(age<2h) in top20 | 3+ | 0~1 | 0 |
| CZ龙头涨跌 | +50%~+500% | -5%~-15% | 横盘/阴跌 |
| 总交易量(TOP10) | > $10M/h | $2~5M/h | < $1M/h |
| 推特/Coolapk讨论热度 | 🔥 刷屏 | 偶尔提到 | 没人说 |

## 实际应用

**例：2026-07-05 BSC 分析**
```
Buy/Sell: 1.25 → 冷却期
新鲜币: 0 → 冷却期
CZ龙头: -9% → 冷却期
结论: 冷却期，等下一波信号
→ 不应该操作，应观察 Solana
```
