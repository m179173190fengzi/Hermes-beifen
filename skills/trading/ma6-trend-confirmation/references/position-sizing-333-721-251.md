# 仓位三分法：333 / 721 / 251（含数学修正）

来源：交易禅师 @shabi2026（2025-11-28）的「333 建仓 / 721 持仓 / 251 止盈」，
经算术核对后修正两处错误。核心判断：**仓位管理的本质是保留选择权，不是「买多少」。**
满仓 = 一次把子弹打光 = 涨了不能加、跌了不能补、崩了跑不掉。

## 1. 三条法则（原版 + 修正）

**建仓 333**：分三批，每批 1/3（信号试探 → 回调加仓 → 反转确认补仓）。

- ⚠️ 修正：原文说「第二批跌 10-15% 加」，但它自己的案例是 17,000 → 16,200（**只跌 4.7%**）
  就加了 —— **规则与案例对不上**，说明作者没严格跑过。
- 🚫 **meme 禁用**：meme 跌 50% 不是「底部」，是「归零中段」。

**持仓 721**：70% 底仓 + 20% 波段 + 10% 备用金。

- 10% 备用金在极端行情只够补一次；20% 做 T 对多数人是负收益操作。
- 原文「机构满仓是 70%，留 30% 现金」不准确：机构做的是**按波动率定头寸**，不是机械留现金。

**止盈 251**：2x 卖 20% / 5x 卖 50% / 10x 清仓。

- ⚠️ **数学错误**：2x 卖 20% 只收回 **40% 本金**，不是「回本加小赚」。
  2x 要回本必须卖 **50%**（50 份 × 2 = 本金）。
- 实测代价：10 倍行情下按 251 执行 = 收回 **5.9 倍**（0.2×2 + 0.5×5 + 0.3×10），
  满仓拿到顶 = 10 倍 → **牺牲 41% 顶部收益换确定性**。
  对拿不到顶部的普通人划算；对真能拿到顶部的，反而少赚。

## 2. 最大的冲突：333 与利弗莫尔完全相反

| | 加仓时机 | 底层假设 |
|---|---|---|
| 利弗莫尔 20/20/20/40 | **涨 10% 加**（越涨越买） | 趋势延续 |
| 333 法则 | **跌 10-15% 加**（越跌越买） | 均值回归 |

**两套不能混用**，先判市场类型再选：

| 市场 | 用哪套 | 理由 |
|---|---|---|
| 4H 均线发散、单边趋势 | 利弗莫尔 | 顺势，错了就砍 |
| 跌无可跌 + 有基本面（BTC/主流现货） | 333 | 逆向摊成本 |
| 微盘 meme | **两套都禁用** | 一次进、绝不补仓、翻倍出本 |

反过来做（事件/meme 重仓摊平、趋势单小仓试错）是最贵的错误。

## 3. 三条铁律

1. **meme 绝不补仓** —— 333 用在 meme 上等于加速爆仓。
2. **浮盈不是钱，卖出才是钱** —— 没有卖出规则的满仓就是等死
   （真实案例：43 万浮盈 → 29 万 → 59 万 → 53 万，判断对牛市却没赚到钱）。
3. **保留选择权** —— 涨了能加、跌了能补、崩了能活。

## 4. 满仓了怎么办

不是砍仓，是**做 T 稀释**：涨 10-15% 卖 20%，跌 10-15% 买回来，逐步把 100% 变成 721。
