# O大打狗打法（蒸馏版）

> 一句话：**打狗不是赌博，是信息差的博弈。**
> 你不是在赌运气，是在赌「你比市场早几秒知道该玩什么角度」。

## 一、决策流程（最重要，按顺序走）

```
① 看到推文/热点
   ↓ 提炼「角度词」——能直接当 ticker 或图片梗用的那个词
② 找「第一个正确的盘」——不是第一个盘
   判据：ticker 对 + 图片是 meme + 台子对（flap/four/pump…）+ 底池对
   ↓
③ 判断类型：PVP 浇给型 还是 发酵型？
   - PVP：赚了就跑（行情好 30 秒不起来直接 sell）
   - 发酵：出本长持（只长持龙头）
   ↓
④ 翻倍出本（本金先撤）—— 每个 meme 玩家的必备动作
```

**顺序不能反**：先有角度词，再找盘。看盘再想角度 = 慢半拍，且容易自我说服。

## 二、三条「一眼塞」法则

| 场景 | 动作 | 试错成本 |
|---|---|---|
| 推文刚出 | 先想角度，再看新盘列表塞第一个对的 | 低 |
| meme 一出来就明显有角度/叙事/发酵空间 | 直接塞 | 高 |
| 看不懂但聪明钱猛冲（新平台/新叙事） | 先上车再研究（**先信吃掉后信**） | 中 |

**同名多盘怎么选**（按优先级）：
1. ticker 正确 + 图片偏 meme 的第一个（现阶段 BSC 审美提高了，别无脑上第一个）
2. 同名太多时 → 上「图片很有感觉」的
3. 行情一般时 → 上「最先 Dev Sell」的
4. 聪明钱猛冲的大盘子 → 不管看不看得懂，先上车（有回调直接跑）
5. 老盘子在底部 → 也可以上

## 三、12 条实战清单（原文压缩，保留关键判断）

0️⃣ **围绕官推玩**（在精不在多）：BSC 火→CZ/何一/币安官推；SOL 火→马斯克/特朗普/toly；币股 meme→各底池官推+创始人（bnc→bnc 官推，nvda→英伟达+老黄）。
1️⃣ **一眼塞**：一直盯战壕「新创建」列表。
2️⃣ **永远不要在没涨时说它起不来；永远不要在涨的时候上车**。买前自问：KOL/车头会不会买？会买就上，不会就别买。
3️⃣ 犹豫错过但角度好 → **等一根红线砸下来再上车**；有内盘车头上车且 K 线有量 → 第一时间跟。
4️⃣ **两类盘**（必须自己判断）：PVP 浇给型=赚了跑；发酵型=出本长持。
5️⃣ 行情好：塞入 **30 秒没起来直接 sell**。
6️⃣ 行情坏：**只上叙事好的长持**。
7️⃣ 不听喊单（除非胜率很高的车头/博主）。
8️⃣ 摒弃普通人思维，切换交易员思维，**适度追涨杀跌**。
9️⃣ **知行合一，尊重第一念头**——后面想来想去都是干扰。
⑩ **判断会不会掀起新热潮**：长拿只拿龙头（一波叙事只有一个龙头）。
⑩① **只做自己的车头**，上车要自信，让车头来抬你；但要多看车头的买卖点复盘。
⑩② **懂得放弃**：一直 P 不过，就换赛道（撸毛/二级/套利）。

## 四、进阶玩法（信息差）

- **衍生盘**：几 M 十几 M 的大 meme 出来后别 FOMO，立刻去抓衍生盘底部（例：币安人生火了→抓其他「xx人生」，只上最底部）。
- **暗线机会**：官推/名人发教程、视频、新功能里若含 CA/钱包地址/tx hash → 全部收藏监控，哪天提示买入直接上车（可遇不可求）。
- **技术佬路线**：写脚本监控新台子/新池子/项目方地址/页面变化 → 抓第一波信息差。
- **不断丰富聪明钱库**：每个火起来的 meme，都去挖「盈利最多 + 进得最早」的那几个钱包。

## 六、事件推演（用户 2026-10 实战提炼，最核心的一节）

> **信息差已经变成「选择差」**：同一条消息大家都看到了，差的是几十秒内知道该买哪个盘。
> 真正厉害的不是币出来后分析得快，是**推文出来那一刻，脑子里已经知道市场会发什么币**。

### 6.1 五条否决清单（3 秒可用）

正向清单（底池对 / Ticker 对 / 图片对 / 发射台对 / 聪明钱猛冲）判断太慢。实战要反过来用——**任何一条不满足，立刻跳过**：

| # | 否决条件 | 判断依据 |
|---|---|---|
| 1 | **不是最早创建的** | 创建时间戳（不是"我第一次看到的时间"）|
| 2 | **Ticker >8 字母 / 带数字** | 传播成本高，梗传不开 |
| 3 | **没有配套图片梗** | 纯文字盘，靠嘴传播，弱一档 |
| 4 | **台子不对**（事件在哪条链火，盘在另一条）| 分流盘没有主战场 |
| 5 | **LP < $10K 或持币 < 200** | 一击必死 |

**五条全过 → 进；任意一条不过 → 走。** 不做"值不值得"这种慢判断。

### 6.2 「看人」三层模型（fomo 车头跟单的正确用法）

打狗越来越看"谁先买了"（名人效应：打出过结果的钱包会被大量监控）。但跟人有反身性：

| 层级 | 情形 | 你的位置 |
|---|---|---|
| 第一层 | 车头买了，你跟着买 | 落后，**你是他的退出流动性** |
| 第二层 | 你先买，车头后来 | 车头**抬你的轿** ✅ 这是目标 |
| 第三层 | 车头钱包被公开监控 | 他买入会被 front-run → **"跟人"策略整体失效** |

结论：**"看人"只能当验证器，不能当主策略。**
- 已进场 → 车头进 = 叙事确认（安心持到翻倍出本）
- 没进场 → 车头进 = 说明你已经慢了，**别追，等回踩**

### 6.3 每日回放训练（替代模糊的"多练"）

1. 取 3 条当天真实推文（CZ / 何一 / 项目官推），**只看推文，不看盘**
2. 写下三样：① 角度词　② 猜的 ticker　③ 猜的台子
3. 去 GMGN 搜，对照实际出的盘：ticker 对没对？台子对没对？第一个盘是哪个？
4. 记录错在哪一类（角度词 / ticker 命名 / 台子判断）

练 20 次，错误会集中到某一环——那才是要补的地方。中文玩家与英文玩家的造词习惯差异，通常体现在 ticker 命名上。

### 6.4 实证案例：$PIERRE（2026-10-19）

事件：尼斯 Micromania 店员 Pierre 对抗抢劫者的爆款视频（评论一边倒夸 Pierre）。

| 盘 | 创建时间 | 结果 |
|---|---|---|
| `D3S6J9s1byrNBt3ZKwEDiPsNRqHtoEP8zQKdhyBdpump` | **00:38** | MC $1.31M，24h **+2951%（约 30x）** ✅ |
| 仿盘 ×7 | 02:10 – 05:12 | 多数 LP $0、MC $3K–$12K，全部归零 ❌ |

主盘结构：持币 4,123｜Top10 20.4%｜bundle 18.1%｜围猎 9.1%｜dev 发过 39 个币且 **creator_close（已清仓）**。

**两个反直觉结论**：
1. **dev 清仓了币还涨 30 倍** → 爆款事件盘的定价权在社区情绪，不在 dev；平时那套硬结构标准在事件盘上要放宽。
2. **"第一个"通常是狙击手批量发的** → 只要 ticker / 台子 / 时间最早对，市场就认它，不必纠结"官方原版"。

**窗口参考**：主盘 00:38 创建，最后一个仿盘 04:36 —— 仿盘在 4 小时内陆续出现；但真正便宜的价格窗口远短于 4 小时。

## 六之三、CA 体检固定四段（用户 2026-11 明确要求）

用户发 CA = 只做体检，不自动监控。**输出必须是这四段，顺序不能变，缺叙事那段直接算不合格。**

### ① 叙事解读（第一段，最重要）
必须回答四个问题，答不上就去查（GMGN link / 官网 / 推特 / TG），不许跳过：
- **是什么梗**：人名？事件？游戏？概念？名字本身是什么意思
- **谁在做**：个人号、团队、还是无主 meme；官推是谁、挂的是不是真背书（例：GTA6 挂 @RockstarGames = 借势，非合作）
- **什么机制**：纯 meme / 有产品 / 有铸造 / 有台子（pump.fun、flap、stonkfun、pons 等），有没有资金真实流进池子
- **为什么现在热**：蹭了什么当下事件（币安 Agentic Wallet、.ai Agent ID、GTA6 发售、Aura 梗…），热度是自然形成还是买量

判分口径：**"真机制" > "蹭热点的好 ticker" > "纯 ticker 盘"**。机制型盘要看抽成比例、邀请返利、阶梯定价藏在哪。

### ② 结构数据
MC / FDV / LP / 24h 量 / 持币 / Top10 / bundle / **围猎** / 机器人 / 台子 / dev 状态 / 币龄。

### ③ 位置
1h/6h/24h 涨跌、成交量衰减曲线（近 1h 量占 24h 量的比例）、买卖笔数比。

### ④ 结论
红/黄/绿 + 三条以内的理由 + 明确的"等什么条件"（MC 到哪、围猎降到哪、量能缩到哪），不给模糊建议。

### 硬门槛
- **围猎 > 25% → 标红，不给入场建议**
- 围猎 > 50% → 一票否决，直接说别碰
- 单一地址持有 > 50% → 必须先查是不是池子/锁仓，不是就直接否

## 六之四、先例六问 + KOL 行为信号（来源：GMGN User Stories #14 / Dani，2026-11）

### 核心认知：看行为，不看言论

Dani 赚的第一桶大钱，来自看到 Ansem 发推说「开了 PumpFun 账号」，而不是看到他喊某个币。

```
第 4 层：KOL 喊 ticker          ← 最晚的信号，也是散户唯一能看到的
第 2 层：KOL 开平台账号 / 改 bio / 关注突变  ← 意图，早 24-72 小时
第 1 层：KOL 建仓（链上可见）
```

**判据：喊单是结果，准备动作是意图。** 只盯喊单的人，永远在给别人抬轿子。

可监控的行为信号（无需 X API）：
- 新开 pump.fun / debot / 某链账号
- 改 bio、换头像、关注列表突变
- 与某个 dev 互关
- **删推**（删推 = 收回承诺，利空信号）

### 先例六问（每个新盘必过）

```
① 这个玩法以前有过吗
② 我喜欢这个叙事吗（主观，但必须回答）
③ 它新鲜吗
④ 能类比成谁
⑤ 有先例吗 —— 先例的峰值多少、多久见顶、之后怎么死的
⑥ 市场会在意吗
```

**第 ⑤ 问是唯一可以量化的，别靠记忆，查库：**

```bash
python3 ~/.hermes/scripts/precedent_db.py report --narrative 猫meme
python3 ~/.hermes/scripts/precedent_db.py add --chain sol --ca <地址> --narrative <标签>
python3 ~/.hermes/scripts/precedent_db.py refresh --all
```

库在 `~/.hermes/data/precedent.db`，字段含 ATH 市值 / 见顶时间 / 当前回撤 / bundle / 围猎 / 币龄。
**样本 < 3 个的叙事分组不可用**（脚本会标 ⚠样本不足）。

### 不对称下注（他的资金分配逻辑）

```
小仓位 × 多次试错 = 允许归零
大仓位 × 少次     = 必须对
```

只做**至少 10x 空间**的标的；不接受「风险 10 赚 8」。
**前提是仓位小到归零不影响下一次出手**——这是纪律，不是勇气。

### 事后复盘（哪怕没买）

没进场的盘也要写三行：

```
为什么涨 / 我漏了什么信号 / 下次什么条件下能提前看到
```

**买过的盘会带情绪，没买的盘才看得清。**

### 不能照抄的三点（必须同时告诉用户）

1. **原文没披露本金**——「30 天 $1.1M」没有分母，$200K 本金是 5.5 倍，$2K 本金是 550 倍
2. **这是 GMGN 的推广内容**——他领了 Rolex / 积分 / 返利，还能召集八位工程师，属深度合作方。「GMGN 好用」要打折，「交易手法」可学
3. **他的「远见」有一半是运气**——他买了 OG 币但 Ansem 站台了另一个，仓位还偏小，是整个板块普涨救了他

**他自己承认的弱点比优点更值得学**：擅长持有，但拿太久、坐过山车、恐慌在底部卖。
