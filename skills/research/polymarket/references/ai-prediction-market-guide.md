# 预测市场 + AI 分析实用指南

## 核心思路

预测市场（Polymarket 等）的价格 = 概率。
AI 的用武之地是**找到市场定价偏差**。

```
AI 算出的概率  ≠  市场赔率
     ↓
   偏差 > 10% → 值得关注
```

## 数据源

| 类型 | 工具 |
|:----|:-----|
| 赔率数据 | Polymarket API（免费，无需认证） |
| AI 分析 | LLM 解读新闻、民调、赛场数据 |
| 自动下单 | Polymarket CLOB API + 钱包签名（EIP-712） |
| 监控通知 | Telegram Bot |

## 三种玩法

### 1️⃣ 找定价偏差（最常用）

```
例：美国大选
  AI分析民调 → Trump 胜率 55%
  市场赔率   → Trump 48%
  偏差 +7%  → 买入 Yes
  等价格回归 → 卖出获利
```

### 2️⃣ 事件驱动

```
事件发生（Fed加息/球员受伤）时：
  1. AI 理解事件含义
  2. 找出受影响的市场
  3. 在价格反应前抢先入场
```

### 3️⃣ 持续监控

```
定时任务（每小时）：
  ├── 扫热门市场
  ├── AI 重新评估概率
  ├── 偏差够大 → 通知/下单
  └── Telegram 推送
```

## Polymarket API 快速参考

```python
# 查热门事件
python3 polymarket.py trending --limit 5

# 搜世界杯
python3 polymarket.py search "World Cup"

# 看具体赛事
python3 polymarket.py event world-cup-winner

# 看某个市场的订单簿
python3 polymarket.py book <token_id>
```
