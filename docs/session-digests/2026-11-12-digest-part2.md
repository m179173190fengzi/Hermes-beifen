## 四、CA 体检固定四段

用户要求：**发 CA 必须带叙事解读，缺叙事段 = 不合格。**

### 四段顺序（不可调换）

```
① 叙事解读 —— 什么梗 / 谁在做 / 什么机制 / 为什么现在热
② 结构数据 —— MC / LP / 持币 / Top10 / bundle / 围猎 / 机器人 / 币龄
③ 位置     —— 涨跌段 + 成交量衰减 + 买卖笔数比 + 大户动向
④ 结论     —— 红黄绿 + 理由 + 「等什么条件」
```

### 硬门槛

```
围猎 > 25%        → 标红，不给入场建议
围猎 > 50%        → 一票否决
单地址 > 50%      → 先查是不是池子/锁仓，不是就直接否
```

### 关键认知

**围猎低 ≠ 安全。** PUSSY 围猎仅 17.3%，但 bundle 64% + 机器人 69%——
操盘手不需要围猎散户，因为**筹码开盘就在自己手里**。

**同期两种剧本高度一致：**

```
       24h 涨幅   1h 变化   bundle   性质
GREEN    +1975%   -21.6%    0.6%     真拉真砸
PUSSY    +1135%   -23.8%   64.4%     机器人对倒
MAX      +6668%   -25.2%   53.8%     真产品+机器人
```

**「拉 10-20 倍 → 第一小时砸 20% 试盘」是当前标准剧本。**

### 判断「派发」的三个证据

```
① 1h 下跌，但买盘笔数 > 卖盘笔数  → 卖的是大户（大额），买的是散户（小额）
② 量能衰减：24h 量 → 6h 量 → 1h 量，掉到 1% 以下
③ 大户净卖出：Top 地址 buy_volume < sell_volume
```

### 老盘复活 vs 新盘启动

**创建时间 > 2 周的币突然 10 倍 = 操盘手拉冷盘出货**，不是叙事启动。
（GREEN MORNING 创建 9-29，11-06 拉 20 倍；mihao 创建 10-25，11-12 已 $16M）

## 五、交易行为审计方法（wallet_audit.py）

### 统计维度

```
胜负分布（笔数/金额/胜率/盈亏比）
持仓时长分档（0-1min / 1-10min / 10min-1h / >1h / >1d）
补仓识别（追涨补 / 补跌 / 平摊）
单笔金额分布（中位数/最大/最小/标准差）
同币 24h 内进出次数
卖出后 N 小时内买回次数
```

### 一次真实审计的结论（匿名化）

```
45 笔卖出 | 胜率 36% | 盈亏比 7.4:1 | 净 +$76

0-1 分钟      32 笔   -$11.21
1-10 分钟      5 笔   -$4.35
10min-1h       3 笔   -$15.81
>1 天          5 笔   +$107.47   ← 全部利润
```

**三个真问题：**

1. **卖出后买回 7 次**（不是"喜欢补仓"）
2. **金额凭手感**：中位 $9.78 / 最大 $49 / 最小 $2.42 / 标准差 $9.89
3. **1 分钟内手痒 32 笔**，合计亏损

### 由此得出的四条硬规则

```
① 补仓只在 -30% / -50% 两档，每次 ≤ 首仓 50%
② 卖出后 24h 禁止买回同一币
③ 单笔下限 $15（低于这个数不值得动手）
④ 单币总投入 ≤ $60
```

## 六、「打提前量」拆解

### 五个来源

| 来源 | 可学性 | 内容 |
|---|---|---|
| 信息层级 | 部分 | 谁比你先知道（0 层项目方 → 5 层 CEX 公告） |
| **结构计算** | **完全可学** | 算得出「谁会买、什么时候砸」 |
| **剧本识别** | **完全可学** | 见过 100 个盘就知道后续 |
| 执行速度 | 部分 | 节点/抢跑（边际收益低） |
| 直觉 | 不可学 | 前四项压缩成本能后的产物 |

### 关键判断

**「预判」90% 是事后叙事。** 实际过程是：试了 5 个，亏 4 个，赢 1 个赚 20 倍；
讲出来只剩那 1 个。

### 结构计算该看什么

```
bundle 比例        → 谁手里有货
LP 占 MC 比例      → 砸下来滑点多少
Top10 分布         → 几个大户 vs 一堆散户
池子锁没锁         → 能不能撤池
dev 历史           → 上一个盘怎么收场
持币增长速度        → 真人在进还是机器人在对倒
前 10 地址的买卖量  → 大户是在进还是在出
```

### meme 剧本库（十几种里最常用的六个）

```
① 老盘复活（数周前的币突然 10 倍）→ 拉高出货
② 开盘直拉（6h 内 10 倍）→ 机器人对倒，1h 内砸 20%
③ 缩量横盘 + 持币增长 → 洗盘，等二次启动
④ 砸盘吸筹（跌 60% 后持币反增）→ 准备二波
⑤ 消息驱动（上 CEX/合作公告）→ 一根阳线出完
⑥ 平台币（有真产品）→ 看平台数据不看 K 线
```

## 七、市场状态判断框架

### 行情是否"发动"的五条可验证信号

```
① BTC 4H 收盘站上 EMA20，且 SMA20 上穿 SMA60
② 稳定币总供应连续 3 天回升（不是单日反弹）
③ 每日新盘数量翻倍
④ 叙事雷达出现「新」叙事 3+ 独立事件（不是 meme 本身）
⑤ 关注钱包开始连续新建仓（不是单笔）
```

**出现三条以上才叫发动；零到一条 = 存量博弈。**

### 2026-11-12 实测状态

```
BTC $73,491：1H/4H 均在 EMA20 下方，4H SMA20 < SMA60 < SMA120（空头排列）
稳定币供应：一周 -$14.2B（2022 熊市以来最大收缩）
叙事面：Meme 币 14 个独立事件 = 共识区 = 派发段
→ 结论：零条满足，不具备发动条件
```

### KOL 喊单的证伪方法

**看量能是否放大。** 若喊单后 1h 成交量仍只有 24h 量的 1%，
说明喊单没有带来增量资金——**是在派发，不是在发动**。

（实测：mihao 被喊"速通千万"，1h 量 $149K = 24h 量的 0.8%，1h 净卖出）
