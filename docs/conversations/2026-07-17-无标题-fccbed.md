### 二、核心理念

LLM Wiki 基于 **Andrej Karpathy 的 LLM Wiki 设计模式**（[llm-wiki.md](https://gist.github.com/karpathy/442a6bf555914893e9891c11519de94f)），核心理念是**用 LLM 增量构建和维护持久化 Wiki**，而非传统 RAG 的"每次查询从头检索"。

**三层架构（忠实继承原始设计）：**
1. **Raw Sources（原始资料）** — 不可变的源文档
2. **Wiki** — LLM 生成的 Markdown 页面（实体、概念、摘要等）
3. **Schema** — 规则和配置文件（schema.md + purpose.md）

**三个核心操作：** Ingest（摄入）、Query（查询）、Lint（检查）

**关键区别 vs 传统 RAG：**
- RAG：每次查询从零检索 + 生成
- LLM Wiki：知识**编译一次，持续更新**，交叉引用已存在，矛盾已标注

### 三、核心功能与亮点

#### 1. 两步思维链摄入（Two-Step Chain-of-Thought Ingest）
- **Step 1（分析）**：LLM 读取资料 → 结构化分析（提取实体、概念、矛盾点、关联建议）
- **Step 2（生成）**：基于分析生成 Wiki 页面（摘要、实体页、概念页、更新 index/overview/log）
- SHA256 增量缓存跳过未变更文件，节省 Token
- 持久化队列支持崩溃恢复、3 次自动重试

#### 2. 四信号知识图谱（Knowledge Graph）
| 信号 | 权重 | 描述 |
|------|------|------|
| 直接链接 | ×3.0 | `[[wikilinks]]` 直接引用 |
| 来源重叠 | ×4.0 | 共享同一原始资料 |
| Adamic-Adar | ×1.5 | 共享共同邻居 |
| 类型亲和 | ×1.0 | 同类页面额外加分 |

- 基于 **sigma.js + graphology + ForceAtlas2** 可视化
- 节点按类型/社区着色，边按权重着色

#### 3. Louvain 社区检测
- 自动发现知识聚类，独立于预设页面类型
- 内聚度评分（< 0.15 标警告）

#### 4. 图谱洞察
- **惊奇连接**：跨社区/跨类型链接自动检测
- **知识空白**：孤立页面、稀疏社区、桥接节点识别
- 一键触发 **Deep Research** 填补空白

#### 5. 多阶段查询检索管线
- **Phase 1**：分词搜索（中英文双语支持）
- **Phase 1.5**：可选向量语义搜索（LanceDB，召回率 58.2% → 71.4%）
- **Phase 2**：图谱 2 跳扩展
- **Phase 3**：预算控制（4K → 1M tokens 可配）
- **Phase 4**：上下文组装+编号引用

#### 6. Rust 后端 Chat Agent
- 工具型 Agent：Wiki/Source/Graph/Web/AnyTXT/Shell/Skills
- Skill 系统：扫描本地 `SKILL.md`，`/skill` 切换
- 生成物预览、流式工具事件

#### 7. Deep Research（深度研究）
- 支持 **Tavily / SerpApi / SearXNG** 多查询网络搜索
- LLM 自动生成搜索主题（基于 overview.md + purpose.md）
- 结果自动合成 Wiki 页面并摄入

#### 8. 多格式文档支持
| 格式 | 解析方式 |
|------|----------|
| PDF | pdf-extract (Rust) + 可选 MinerU |
| DOCX | docx-rs → 结构化 Markdown |
| PPTX | ZIP+XML 逐页提取 |
| XLSX/XLS/ODS | calamine 多表支持 |
| EPUB/MOBI | 元数据+章节提取 |
| 图片/音视频 | 原生预览/播放 |
| 网页 | Chrome 扩展 + Readability.js |

#### 9. Chrome 网页剪藏扩展
- Manifest V3，Readability.js 精确提取
- Turndown.js HTML→Markdown 转换
- 本地 HTTP API 通信，自动摄入触发

#### 10. MCP Server + HTTP API + AI Agent Skill
- 内置 `127.0.0.1:19828` JSON API（health/projects/search/chat/graph/rescan）
- 内置 MCP Server（`mcp-server/`），一键接入 MCP 客户端
- 配套 Agent Skill：`npx skills add https://github.com/nashsu/llm_wiki_skill.git --skill llm-wiki`

#### 11. 异步审核系统
- LLM 标记需人工判断项（创建页面/深度研究/跳过）
- 预生成搜索查询，不阻塞摄入

#### 12. 项目导出/导入
- ZIP 归档跨设备迁移
- 确定性重建 wiki/index.md

#### 13. 其他亮点
- KaTeX 数学公式 + Mermaid 图表渲染
- DeepSeek/QwQ `` 块流式展示
- 文件删除级联清理（共享实体保护、wikilink 清理）
- 场景模板（研究/阅读/个人成长/商业/通用）
- 多 LLM 提供商（OpenAI/Anthropic/Google/Ollama/自定义）
- 多对话持久化、引用面板、重新生成、保存到 Wiki

### 五、部署方式

#### 方式 A：预编译二进制（推荐）
- **macOS**：`.dmg`（Apple Silicon + Intel）
- **Windows**：`.msi`
- **Linux**：`.deb` / `.AppImage`
- 从 [GitHub Releases](https://github.com/nashsu/llm_wiki/releases) 下载

#### 方式 B：从源码构建
```bash
# 前置条件：Node.js 20+, Rust 1.70+
git clone https://github.com/nashsu/llm_wiki.git
cd llm_wiki
npm install
npm run tauri dev      # 开发模式
npm run tauri build    # 生产构建
```

#### Chrome 扩展
1. 打开 `chrome://extensions`
2. 启用「开发者模式」
3. 加载 `extension/` 目录

#### MCP Server 构建
```bash
npm run mcp:build
```

### 六、项目结构

```
my-wiki/
├── purpose.md              # 目标、关键问题、研究范围
├── schema.md               # Wiki 结构规则
├── raw/
│   ├── sources/            # 上传文档（不可变）
│   └── assets/             # 本地图片
├── wiki/                   # LLM 生成的 Wiki
│   ├── index.md            # 内容目录
│   ├── log.md              # 操作历史
│   ├── overview.md         # 全局概要（自动更新）
│   ├── entities/           # 人物、组织、产品
│   ├── concepts/           # 理论、方法、技术
│   ├── sources/            # 资料摘要
│   ├── queries/            # 保存的聊天+研究
│   ├── synthesis/          # 跨资料分析
│   └── comparisons/        # 并列对比
├── .obsidian/              # Obsidian 仓库配置（自动生成）
└── .llm-wiki/              # 应用配置、聊天历史、审核项
```

### 八、与 Karpathy 原始设计的对比

| 维度 | 原始设计（抽象模式） | LLM Wiki（本项目） |
|------|---------------------|-------------------|
| 形态 | CLI/Agent 复制粘贴模式 | **跨平台桌面应用**（Tauri v2） |
| 摄入 | 单步 LLM 调用 | **两步思维链**（分析+生成） |
| 存储 | 纯文本文件 | **增量缓存 + 持久化队列** |
| 查询 | 简单搜索 | **4 阶段流水线**（分词+向量+图谱+预算） |
| 图谱 | 仅 wikilinks | **4 信号关联度 + Louvain 社区 + 洞察** |
| 编辑 | 手动或 LLM | **Milkdown WYSIWYG** |
| 聊天 | 单次 | **多对话持久化 + Agent + Skills** |
| 扩展 | 无 | **HTTP API + MCP + Chrome 扩展** |
| 文档 | 仅 Markdown | **PDF/DOCX/PPTX/XLSX/EPUB/网页** |
| 研究 | 无 | **Deep Research + 多搜索 Provider** |
| 审核 | 手动 | **异步审核队列** |
| 跨平台 | 不涉及 | **macOS/Windows/Linux CI/CD** |
| i18n | 无 | **中英文界面** |
| 格式 | 纯文本 | **KaTeX + Mermaid + 图片 + 音视频** |
