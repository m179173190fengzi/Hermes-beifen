如果没反应，试试以下几个排查：

### 1. 确认托盘图标存在
看看系统托盘（右上角）有没有 fcitx 的键盘图标（一只小键盘或一个"拼"字）。有的话右键点它查看输入法列表，确认 sogoupinyin 在列表中且勾选了。

### 2. Wayland 兼容问题
我看到你在用 Wayland。fcitx4 在 Wayland 下可能不工作，需要加环境变量。运行：

```
export GTK_IM_MODULE=fcitx
export QT_IM_MODULE=fcitx
export XMODIFIERS=@im=fcitx
export SDL_IM_MODULE=fcitx
```

这些通常已经在你的 ~/.pam_environment 和 /etc/environment 里了（我看到有的），但如果还是不行，试试：

```
im-config -n fcitx
```

然后**重启**（或注销重新登录）。

### 3. 重启 fcitx
```
fcitx4 -r
```

### 4. 如果还是不行
可能是 sogoupinyin 本身与 fcitx4 的兼容问题，可以试试看 fcitx5 + fcitx5-chinese-addons 或者 ibus-rime。
