### 📋 工作方式

一个 `gateway-watchdog.sh` 脚本 + cron 定时任务，每 **5分钟** 自动检查一次：

| 状态 | 行为 |
|------|------|
| ✅ Gateway 正常运行，无错误 | **静默** — 不打扰你 |
| ⚠️ Gateway 正常运行，但最近10分钟有 ERROR 级别日志 | **发通知给你** |
| ❌ Gateway 服务挂了 | **自动尝试重启**，并通知结果 |

### 🔍 脚本做了什么

```
~/.hermes/scripts/gateway-watchdog.sh
```

1. 检查 `hermes-gateway.service` 是否 active
2. 如果不是 → 尝试 `systemctl --user restart`，等待5秒再看，汇报结果
3. 如果是 → 检查 `gateway.log` 最近10分钟有无 ERROR/CRITICAL/Traceback
4. 一切正常 → 零输出，零通知

### 🕐 Cron 任务

- 名称：`gateway 通道健康检查`
- 每 5 分钟跑一次，永久循环
- `no_agent=True` 模式（不消耗 token，直接跑脚本）
- 有异常会直接发消息到当前聊天

现在开始每5分钟就会自动盯着 gateway 了，异常时你会第一时间知道！🎉

Ubuntu 关机重启几个常用命令：

## 🔌 关机

```bash
# 立即关机
sudo shutdown -h now

# 一分钟后关机
sudo shutdown -h +1

# 指定时间关机（比如23:00）
sudo shutdown -h 23:00

# 或者
sudo poweroff
```

## 🔄 重启

```bash
# 立即重启
sudo shutdown -r now

# 一分钟后重启
sudo shutdown -r +1

# 或者
sudo reboot
```

## ⏹ 取消关机/重启

```bash
# 如果已经设定了定时关机，取消它
sudo shutdown -c
```

---

**最常用的两个：**
- 关机 → `sudo shutdown -h now`
- 重启 → `sudo reboot`

记得加 `sudo`，普通用户没权限关机 😄

```

2. 对比市场赔率（比如 45%）
3. 如果偏差够大 → 下注
```

- 美国大选期间，AI 实时分析各州民调、博彩赔率、社交媒体情绪

  1. 扫一遍 Polymarket 所有热门市场
  2. 比对 AI 预测 vs 市场赔率
  3. 发现有偏差 → 自动下单
  4. Telegram 发通知
```

#### 方式三：事件驱动交易

```
当一个事件发生时（比如 Fed 加息），AI 立即：
  1. 理解事件含义
  2. 找出受影响的市场
  3. 在价格反应前抢先下单

MCP 简单来说就是 **给 Hermes 外挂能力的插件系统**，不需要改 Hermes 代码就能加功能。

## 🔌 MCP 是什么

```
MCP 服务器 = 一个独立的小程序，提供特定功能
Hermes 启动时自动连接它，把你提供的功能变成可以调用的"工具"
```

比如你配一个文件系统 MCP，Hermes 就能读你电脑上任何目录的文件；配一个 GitHub MCP，Hermes 就能直接操作仓库。

## 🎯 实际例子

### 装个时间服务器
```yaml
# ~/.hermes/config.yaml 里加上
mcp_servers:
  time:
    command: "uvx"
    args: ["mcp-server-time"]
```
Hermes 就能直接告诉你「现在几点」，不用查浏览器。

### 装个文件系统
```yaml
mcp_servers:
  filesystem:
    command: "npx"
    args: ["-y", "@modelcontextprotocol/server-filesystem", "/home/wei/projects"]
```
Hermes 就能直接读项目文件、写文件、列目录。

### 装个 GitHub 管理器
```yaml
mcp_servers:
  github:
    command: "npx"
    args: ["-y", "@modelcontextprotocol/server-github"]
    env:
      GITHUB_PERSONAL_ACCESS_TOKEN: "你的token"
```
Hermes 就能直接创建 Issue、提 PR、查看代码。
