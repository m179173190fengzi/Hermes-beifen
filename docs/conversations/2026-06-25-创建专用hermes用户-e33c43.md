
### 🚀 使用方式

**1. 先编辑配置文件** — 填入你的 OKX API 信息：
```bash
nano ~/ft_userdata/user_data/config-okx.json
```
需要填写：`key`、`secret`、`password`（API Passphrase）

**2. 下载回测数据（先用 dry-run 验证）**：
```bash
cd ~/ft_userdata
./freqtrade.sh download-data -t 5m --days 30
```

**3. 回测策略**：
```bash
./freqtrade.sh backtesting --strategy SampleStrategy --timerange 20260601-
```

**4. Dry-run 模拟交易**（不花真钱）：
```bash
./freqtrade.sh trade --dry-run
```

**5. 开启 Web 管理界面**：
```bash
./freqtrade.sh webserver
```
然后访问 http://localhost:8080

**6. 正式交易**（修改 `config-okx.json` 里 `dry_run: false`）：
```bash
./freqtrade.sh trade
```

### ⚠️ 重要提醒
- 先 **dry-run 跑至少一周**，确认策略没问题再上真金白银
- 配置文件里 `trading_mode: "futures"` + `margin_mode: "isolated"`（逐仓更安全）
