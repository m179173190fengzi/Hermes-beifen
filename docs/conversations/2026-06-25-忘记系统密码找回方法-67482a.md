## 方法一：GRUB 恢复模式（推荐，最快）

1. **重启电脑**
2. **在 GRUB 引导菜单出现时**，快速按 `Shift`（传统 BIOS）或 `Esc`（UEFI）进入菜单
3. 选择 **Advanced options for Ubuntu** → **Recovery mode**
4. 在 recovery 菜单中选择 **root** — 会直接拿到 root shell
5. 执行：
   ```bash
   mount -o remount,rw /
   passwd wei
   ```
   输入新密码（两次确认）
6. 然后 `reboot` 重启

---

## 方法二：GRUB 编辑内核参数

如果 recovery mode 进不去，可以这样：

1. **重启**，在 GRUB 菜单按 `e` 编辑启动项
2. 找到以 `linux` 开头的那一行
3. 在行尾加上：`init=/bin/bash`
4. 按 `Ctrl+X` 或 `F10` 启动
5. 进入 bash shell 后执行：
   ```bash
   mount -o remount,rw /
   passwd wei
   ```
6. 输入新密码，然后 `exec /sbin/init` 继续启动或 `reboot -f`

---

## 方法三：Live USB（如果前两种不行）

1. 用另一台电脑制作 Ubuntu Live USB
2. 插上 U 盘，从 U 盘启动
3. 选择"试用 Ubuntu"（Try Ubuntu）
4. 挂载系统分区：`sudo mount /dev/nvme0n1p2 /mnt`（分区名用 `lsblk` 确认）
5. 如有单独的 boot 分区也挂上：`sudo mount /dev/nvme0n1p1 /mnt/boot`
6. 进入 chroot：`sudo chroot /mnt`
7. 重置密码：`passwd wei`
8. `exit` 后重启，拔掉 U 盘

---

你想试试哪种方法？如果对 GRUB 操作不太熟悉，**方法一（Recovery Mode）** 是最简单的。执行完记得把新密码记下来 😄
