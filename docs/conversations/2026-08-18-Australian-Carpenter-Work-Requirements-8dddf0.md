# 澳洲木工打工核心条件

结论：木工(ANZSCO 331212)在澳洲是**紧缺职业**，在Core Skills Occupation List上，各州都缺人。门槛=**职业评估 + 英语 + 年龄 + 工作经验**，四条路可走。

## 硬性条件（不管走哪条路）

**1. 职业评估（最大门槛）**
- 机构：TRA（Trades Recognition Australia）
- 需要证明：正式木工培训/证书 + 工作经验
- 国内的职业技能等级证书（人社部木工证）可以当学历材料递
- 如果证书不被认，可走 OSAP（海外技能评估，含技术面试）或先留学

**2. 工作经验**
- 通常要求 **3年以上** 全职木工经验，评估时主要看这个
- 材料：工作证明、工资流水、税单、合同

**3. 英语（最低档）**
- 雇主担保482/SID：雅思总分5.0（单项≥5.0）
- 技术移民189/190：雅思4个6
- PTE/托福同等成绩都认

**4. 年龄**
- 转PR必须 **<45岁**（482/SID本身没上限，但转永居必须在45前）
- 越年轻打分越高，25-32岁加分最多

## 四条路径

**A. 雇主担保（最主流、最快）**
- SID签证（2024年12月新规，替代旧482）→ 干满2年 → 转186永居
- 薪资门槛：年薪≥$73,150 AUD
- 难点：找**真实雇主**。中介市场水很深，5-20万人民币的"包工"很多是坑，2025年澳洲移民局在严打假担保
- 适合：有3年+经验、英语够5.0的人

**B. 独立技术移民 189/190**
- 打分制，65分起，木工邀请分数相对友好
- 190州担保更实际：WA、SA、QLD、NT都缺木工，州政府愿意捞人
- 需要：雅思4个6 + TRA评估 + 年龄加分
- 优点：一步到位全家PR，不用被雇主绑住

**C. 留学转工（最稳、最贵）**
- TAFE读 Certificate III in Carpentry（1.5-2年，学费约$15K-30K/年）
- 毕业 → 485工签 → 凑经验 → 雇主担保转PR
- 总成本约50-100万人民币，周期3-5年
- 适合：英语能考到5.5、不差钱、想要稳妥路径

**D. 打工度假 462（试水）**
- 18-30岁、抽签制（中国每年5000名额）、需要大学学历或2年大专在读
- 可以干建筑（2024年起同一雇主最长12个月）
- 不能直接转PR，但是低成本试水的跳板

## 行情

- 木工时薪 **$35-55 AUD**，年收入 **$85K-110K AUD**
- 基建+住宅双缺口，全境紧缺，不需要担心没活
- 配偶可全职工作，孩子公立学校免费

## 你的情况最实际的两条

1. 有国内木工证+3年经验 → 冲**A雇主担保**或**B州担保**，先搞定TRA评估（费用约$1,000-2,000 AUD）
2. 经验不够或证书不被认 → **C留学**是唯一稳路

## TRA职业评估：中国护照木工(331212)完整清单

**先说关键点：中国护照的木工不走MSA（$795那个），走OSAP**（Offshore Skills Assessment Program）。TRA官网明确把Carpenter+China列在OSAP国别清单里。雇主担保482/SID则走TSS评估。两条路材料、流程基本一样。

### 评估流程（两步）
1. **文件评估**（Documentary Evidence Assessment）——RTO审核你的学历+工作证据
2. **技术面试**（Technical Interview）——技师面试，**全英文，不能带翻译**，可在线（需电脑+10Mbps网速）

### 材料清单（缺一不可，否则拒）
- **护照**身份页（彩色扫描，150dpi+，单文件≤10MB）
- **学历/学徒证书** + 完整成绩单（含起止日期、课程明细）
- 每段工作经历一份 **Employer Template**（雇主模板）：雇佣起止日期、工时、岗位、详细工作内容、公司抬头纸、签字人联系方式
- **工资证据**：每年至少2种——税单/个税记录、3张工资单、社保记录、银行流水（显示雇主名+工资入账）
- 自雇的话：营业执照、年检、客户发票、银行流水
- 非英文材料：**NAATI认证翻译**（境内）或官方认证翻译+盖章（境外）

### 经验要求（Pathway 1，无澳洲学历）
木工属 **non-licensed trade**（licensed只指电工）：
- 有正式培训（国内木工职校/证书）→ **3年**全职经验
- 无正式培训 → **5年**经验
- 必须含：申请前3年内有**12个月**全职木工经验
- 兼职按小时折算

### 费用（AUD，2025年9月版TSS费率，OSAP同结构）
- 文件评估：**$1,120**
- 技术面试（Pathway 1）：**$2,000**
- 合计约 **$3,120**（~1.5万人民币）
- 复审：$700 / 重新评估：$450-1,000
- 签证卡支付，不退费（评估开始后）

### 时限
- 文件评估+技术面试全程约 **9周**（decision-ready材料提交起）
- 失败后28天内可申诉，12个月内可重评一次

### 重要细节
- 成功通过non-licensed评估会**颁发Certificate III in Carpentry澳洲学历**——这就是你之前问的留学路径里那个证，等于直接省了TAFE学费
- 中国国内的木工职业技能等级证书可作为"正式培训"证据，但**必须能通过TRA验证**（学校/人社局能出官方验证）
- 全程必须"decision-ready"提交，缺材料直接拒

### 你的情况怎么走
有国内木工证+3年经验 → 材料齐的话直接申OSAP（$3,120）→ 通过拿Certificate III → 配合雅思5.0/4个6走雇主担保或189/190。
