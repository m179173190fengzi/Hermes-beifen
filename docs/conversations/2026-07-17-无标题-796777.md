### 核心功能

**四字 API**（顶层调用入口）：

| 操作 | 功能 |
|------|------|
| `cognee.remember()` | 持久化存储数据到知识图谱 + 向量库；或写入 session 缓存（快速记忆） |
| `cognee.recall()` | 检索记忆：自动路由搜索策略（会话缓存优先，回退到图/向量混合搜索） |
| `cognee.forget()` | 删除数据集或所有记忆 |
| `cognee.improve()` | 自我改进：在认知化后补充三元组嵌入、索引、桥接会话到永久图 |

**支持 18 种搜索类型** 自动路由（SearchType 枚举）：
- `SUMMARIES` / `CHUNKS` / `RAG_COMPLETION` / `HYBRID_COMPLETION`
- `GRAPH_COMPLETION` / `GRAPH_COMPLETION_DECOMPOSITION` / `GRAPH_SUMMARY_COMPLETION`
- `TRIPLET_COMPLETION` / `CYPHER` / `NATURAL_LANGUAGE`
- `FEELING_LUCKY` / `TEMPORAL` / `CODING_RULES` / `AGENTIC_COMPLETION` 等

**核心特性亮点**：
1. **企业知识大脑** — 统一多数据源，为 AI Agents 提供领域知识
2. **记忆层次** — 会话级快速缓存 + 持久化知识图谱，自动桥接
3. **认知科学启发** — 自动本体生成，知识图谱关系随数据演化
4. **Agent 内存** — 通过 Python 装饰器 `@agent_memory` 自动捕获 Agent 的提示词、工具调用、响应
5. **自改进流程** — 工作流结束后自动 enrich 图索引和嵌入
6. **多租户隔离** — 用户/租户级别数据隔离和权限控制
7. **完全可观测** — 内建 OpenTelemetry 追踪，支持 OTEL collector
8. **BEAM 基准** — 100K tokens 设置下 0.79（超此前 SOTA 0.735），10M tokens 下 0.67
9. **反馈闭环** — Agent 可从用户反馈中学习和自我修正

### 项目架构

```cognee/
├── __init__.py              ← 顶层导出：add, cognify, search, remember, recall 等
├── low_level.py             ← DataPoint 基类 + setup 引擎
├── api/                     ← FastAPI 应用 + 版本化路由
│   └── v1/
│       ├── add/             ← 数据接入（文件、文本、URL 等）
│       ├── cognify/         ← 认知化管道（chunk → extract → graph → vector）
│       ├── remember/        ← 统一记忆入口（桥接了 add + cognify + improve）
│       ├── recall/          ← 统一检索入口（session → graph 自动回落）
│       ├── search/          ← 18 种搜索类型的底层实现
│       ├── improve/         ← 自我改进管道
│       ├── forget/          ← 删除操作
│       ├── serve/           ← 连接 Cognee Cloud / 远程实例
│       └── visualize/       ← 图可视化
├── infrastructure/          ← 基础设施适配层（可插拔）
│   ├── databases/
│   │   ├── graph/           ← 图数据库适配器
│   │   │   ├── kuzu/        ← KùzuDB (嵌入式)
│   │   │   ├── neo4j_driver/← Neo4j
│   │   │   ├── neptune_driver/ ← Amazon Neptune
│   │   │   ├── postgres/    ← PostgreSQL 图存储（纯 SQL 关系图）
│   │   │   └── ladybug/     ← 内部图引擎
│   │   ├── vector/          ← 向量数据库适配器
│   │   │   ├── lancedb/     ← LanceDB (嵌入式)
│   │   │   ├── pgvector/    ← pgvector
│   │   │   └── ...
│   │   ├── cache/           ← 会话缓存（SQLite / Redis / fakeredis）
│   │   └── relational/      ← 关系数据库（SQLAlchemy + 迁移）
│   └── llm/                 ← LLM 提供商适配器
│       ├── prompts/         ← 提示词模板
│       ├── tokenizer/       ← 分词器
│       └── extraction/      ← 结构化输出框架
├── modules/                 ← 领域逻辑
│   ├── graph/               ← 图核心（CogneeGraph, RDF 转换）
│   ├── retrieval/           ← 检索上下文提供者
│   ├── search/              ← 搜索策略实现
│   ├── chunking/            ← 文本分块
│   ├── cognify/             ← 认知化处理
│   ├── memify/              ← 记忆化（技能改进等）
│   ├── ontology/            ← 本体（RDF/XML 生成与导入）
│   ├── agent_memory/        ← Agent 记忆装饰器
│   ├── session_lifecycle/   ← 会话生命周期管理
│   ├── session_distillation/← 会话蒸馏（提取长期模式）
│   ├── users/               ← 用户 & 租户管理
│   ├── tools/               ← 工具和技能系统
│   └── observability/       ← 可观测性（OpenTelemetry）
├── tasks/                   ← 可复用任务（代码图、网页抓取等）
├── memory/                  ← 内存条目类型（QAEntry, TraceEntry, FeedbackEntry）
├── migration/               ← 从 Mem0、Zep、Letta 等迁移
├── pipelines/               ← 管道引擎（DAG 定义、Drop 操作）
├── eval_framework/          ← 评估框架（BEAM 基准、deepeval）
├── cli/                     ← 命令行界面
└── tests/                   ← 单元测试、集成测试、CLI 测试

cognee-mcp/                  ← MCP 服务器（SSE/HTTP/stdio 传输）
cognee-frontend/             ← Next.js UI 前端
distributed/                 ← 分布式部署脚本（Modal、Fly.io、Railway）
deployment/                  ← Helm Chart 及部署工具
examples/                    ← 示例代码和教程
```

#### 2. Docker Compose（推荐本地开发）
```bash
docker compose up                                    # API 在 :8000
docker compose --profile ui up                       # + 前端 :3000
docker compose --profile mcp up                      # + MCP 服务器 :8001
docker compose --profile postgres up                 # + PostgreSQL+pgvector
docker compose --profile neo4j up                    # + Neo4j
```

#### 3. 预构建 Docker 镜像
```bash
docker run --env-file ./.env -p 8000:8000 cognee/cognee:main
docker run -e TRANSPORT_MODE=http --env-file ./.env -p 8000:8000 cognee/cognee-mcp:main
```

#### 4. 1-Click 部署平台

| 平台 | 方式 |
|------|------|
| **Cognee Cloud** | 托管服务，`await cognee.serve()` 一键连接 |
| **Modal** | `bash distributed/deploy/modal-deploy.sh` |
| **Railway** | `railway init && railway up` |
| **Fly.io** | `bash distributed/deploy/fly-deploy.sh` |
| **Render** | 一键部署按钮（含托管 Postgres） |
| **Daytona** | 云沙箱（SDK 或 CLI） |
| **Kubernetes** | Helm Chart（`deployment/helm/`） |

#### 5. "全栈 Postgres" 模式
所有记忆层运行在单一 PostgreSQL 实例上（图+向量+会话+元数据），无需额外数据库服务：
```bash
pip install "cognee[postgres]"
# 设置 DB_PROVIDER=postgres, VECTOR_DB_PROVIDER=pgvector, GRAPH_DATABASE_PROVIDER=postgres
```

### 使用场景

1. **客户支持 Agent** — 跨会话维护客户交互历史，自动关联相似案例和解决方案
2. **专家知识蒸馏（SQL Copilot）** — 抓取专家级查询模式，帮助初级分析师重用复杂知识和推理
3. **Coding Agent（Claude Code 插件）** — 跨 Claude Code 会话保持项目上下文和编码偏好的持久记忆
4. **企业知识管理** — 从 PDF、文档、网页、数据库统一摄取，构建可查询的"企业大脑"
5. **Agent 评估与自我改进** — 自动追踪 Agent 行为，从反馈中学习和修正
