## Hermes Agent WSL 安装步骤

前提：Windows 已装好 WSL 2 + Ubuntu 24.04，打开 WSL 终端。

---

### 第一步：更新系统 & 安装 pipx

```bash
sudo apt update && sudo apt upgrade -y
sudo apt install pipx -y
pipx ensurepath
source ~/.bashrc
```

> ⚠️ Ubuntu 24.04 有 PEP 668 保护，**不要用** `pip3 install`，只能用 pipx。

---

### 第二步：安装 Hermes

```bash
pipx install hermes-agent
hermes --version
```

确认输出版本号。

---

### 第三步：运行 setup 向导

```bash
hermes setup
```

选 **2 (Full setup)**，不要选 Quick Setup（需要 Nous Portal）。

| 提示 | 填什么 |
|------|--------|
| Provider | 选对应数字 (DeepSeek/OpenRouter/等) |
| API Key | 粘贴你的 key |
| Base URL | 默认即可 |
| Model | 默认即可 |
| Execution mode | 默认 (local) |
| Telegram | 输入对应数字（如22）**先按数字切到 ON**，再填 Bot Token 和 Allowed Users |
| Image gen | 9 (Skip) |
| Vision/Aux | 默认 (Auto) |
| Nous Portal | **n** (除非你有订阅) |

---

### 第四步：Telegram 代理配置（WSL 必须）

WSL 里 `127.0.0.1` 指的是 WSL 虚拟机本身，**不是 Windows 宿主机**。需要找 Windows 的真实 IP：

```bash
# 找到 Windows 宿主机 IP
ip route | grep default | awk '{print $3}'
# 比如输出: 172.28.0.1
```

然后用这个 IP 配代理（假设你的 Windows Clash/FLClash 端口是 7890）：

```bash
# 写入 ~/.bashrc 持久化
echo 'export HTTP_PROXY=http://172.28.0.1:7890' >> ~/.bashrc
echo 'export HTTPS_PROXY=http://172.28.0.1:7890' >> ~/.bashrc
source ~/.bashrc
```

> ⚠️ 把 `172.28.0.1` 换成你 `ip route` 输出的实际 IP。

---

### 第五步：启动 Telegram Gateway

```bash
hermes gateway run
```

看到 `Connected to Telegram` 就成功了。

后台持久运行：

```bash
hermes gateway install
hermes gateway start
```

---

### 注意事项

1. **WSL 关闭后 gateway 会挂** — 需要在 `/etc/wsl.conf` 加 `systemd=true` 才能让 systemd 服务持久：
   ```bash
   sudo tee -a /etc/wsl.conf <<< "[boot]"
   sudo tee -a /etc/wsl.conf <<< "systemd=true"
   ```
   然后退出 WSL，在 PowerShell 里运行 `wsl --shutdown`，再重开 WSL。

2. **DashScope/千问用户** — 如果用中国区 DashScope key，必须设国内 endpoint：
   ```bash
   hermes config set model.base_url https://dashscope.aliyuncs.com/compatible-mode/v1
   ```

3. **不要跨机器复制 config.yaml** — 每台机器单独跑 `hermes setup`，只迁移 `.env` 里的 key。

4. **`hermes config set telegram.bot_token` 会报错** — 不要用这个命令设 TG token，走 `hermes setup` 或直接编辑 `.env`：
   ```bash
   echo 'TELEGRAM_BOT_TOKEN=*** >> ~/.hermes/.env
   ```

5. **确认 Gateway 状态**：
   ```bash
   hermes gateway status
   hermes doctor
   ```

## 完整版：从零装 WSL + Hermes

### 一、Windows 上装 WSL

**在 Windows 的 PowerShell（管理员）里运行：**

```powershell
# 装 WSL 2 + Ubuntu 24.04
wsl --install -d Ubuntu-24.04
```

装完重启电脑。

---

### 二、首次进入 WSL

重启后打开 **Windows Terminal**（或 cmd 输入 `wsl`），会提示创建 Linux 用户名和密码：

```
Enter new UNIX username:  # 随便填，比如 fengzi
New password:              # 随便设
```

完成后你就进了 WSL 的 Linux 终端了。

---

### 三、装 Hermes

在 WSL 终端里逐条复制：

```bash
# 1. 更新系统
sudo apt update && sudo apt upgrade -y

# 2. 装 pipx（不要用 pip3）
sudo apt install pipx -y
pipx ensurepath
source ~/.bashrc

# 3. 装 Hermes
pipx install hermes-agent

# 4. 确认版本
hermes --version
```

---

### 四、配置 Hermes

```bash
hermes setup
```

选 **2 (Full setup)**，按提示选模型、填 API Key、设 Telegram。

> Telegram 配置时：先按数字（如 22）把 Telegram 切换到 ON，再一步步填 Bot Token 和 Allowed Users。

---

### 五、配代理（WSL 必要）

```bash
# 找 Windows 宿主机 IP
ip route | grep default | awk '{print $3}'
# 输出类似 172.28.0.1

# 写入 .bashrc 持久化（替换 IP）
echo 'export HTTP_PROXY=http://172.28.0.1:7890' >> ~/.bashrc
echo 'export HTTPS_PROXY=http://172.28.0.1:7890' >> ~/.bashrc
source ~/.bashrc
```

---

### 六、启动 Telegram

```bash
hermes gateway run
```

看到 `Connected to Telegram` 就完成了。

---

### 💡 关键提示

- **WSL 关掉重开会丢失网关** — 如果关过 WSL，重开后先 `source ~/.bashrc` 然后 `hermes gateway run`
- **如果是中国区 DashScope key**：`hermes config set model.base_url https://dashscope.aliyuncs.com/compatible-mode/v1`
- **不要 `pip3 install`**，Ubuntu 24.04 强制用 pipx
