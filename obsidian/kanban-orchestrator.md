# Kanban 编排器

## 描述
Kanban 工作流中的编排节点（Orchestrator），负责分析用户请求后将大型任务分解为多个可执行的子任务，并分发给工作节点。

## 用途
- 将复杂需求拆解为结构化子任务
- 协调多个工作节点的执行顺序
- 跟踪任务依赖关系和进度
- 汇总子任务结果为最终输出

## 工作流程
1. 接收用户输入（大型任务）
2. 分析并分解为子任务列表
3. 按依赖关系排序并分配优先级
4. 分发子任务给 Kanban Worker
5. 收集结果并合并为最终输出

## 使用示例
```
用户: "创建一个完整的博客系统"
编排器分解:
  [1] 搭建项目骨架 (Worker A)
  [2] 实现数据库模型 (Worker B) → 依赖 [1]
  [3] 实现 API 路由 (Worker C) → 依赖 [2]
  [4] 实现前端页面 (Worker D) → 依赖 [3]
```
